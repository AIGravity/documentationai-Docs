## Overview

This changelog records verified, user-facing Gravity platform changes. Entries focus on shipped outcomes and link to the relevant setup, architecture, operations, and release documentation.

## Release history

<Update label="v0.1.0" description="Initial platform foundation" tags={["feature", "improvement"]}>

### New features

- **Remix web app foundation shipped.** Gravity now includes a runnable web application foundation for the user-facing experience. Start with the [Quickstart](/quickstart), then review the [Architecture overview](/architecture-overview) for how the web app fits into the platform.
- **NestJS API health endpoint shipped.** The API service exposes a health check that confirms the service is reachable. See [Health Checks](/health-checks) for the current endpoint behavior and verification steps.
- **FastAPI AI service health endpoint shipped.** The AI service exposes its own health check so operators can verify that the AI service process is responding. See [Health Checks](/health-checks) for the expected response.
- **Automated service release packaging shipped.** Each service can be versioned, packaged, and released independently through the documented automation. Review [Service Versioning](/service-versioning) and [CI/CD Pipelines](/ci-cd-pipelines) for the release flow.

### Updates

- **Platform documentation now reflects the shipped foundation.** Setup, architecture, health check, versioning, and CI/CD pages describe the current service boundaries and release behavior.

### Bug fixes

No user-facing bug fixes shipped in this entry.

</Update>

## How to read this changelog

Scan from top to bottom when you want the newest information first. Read each entry in order: new features first, then updates, then bug fixes. If an entry has no user-facing fixes, the bug fixes section says so directly.
