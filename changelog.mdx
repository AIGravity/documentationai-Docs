## Overview

This changelog tracks notable product changes, organized by release with new features first, then updates, then bug fixes.

## Release history

### July 2025

**Bug Fixes**

- Tool selections now influence agent recommendations. When you pick tools during the recommendation flow, agents that support those tools are ranked higher in your results. Previously, tool selections were captured but had no effect on ranking.

  Learn more: [AI Service Foundation](/ai-service-foundation)
