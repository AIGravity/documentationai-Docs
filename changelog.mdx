## Overview

This changelog tracks notable product changes to the Gravity platform. Entries are organized newest-first, with new features, updates, and bug fixes grouped under each release.

<Update label="2026-07" description="July 2026" tags={["feature", "improvement", "bugfix"]}>

### New Features

- **Agent quality scoring** — Every agent now receives a quality score from `0` to `100` when you submit it for review and again after publishing. Scores reflect output quality, reliability, speed, and cost across multiple use cases.
- **Quality-based auto-rejection** — Agents that fall below the minimum quality standard are automatically rejected with guidance to refine the workflow and resubmit.
- **Trigger confirmation prompt** — Before you activate a recurring agent that runs on app events, Gravity now shows a prompt explaining exactly when the agent will fire.
- **Leaderboard redesign** — The leaderboard now includes a prize podium for top entries, a countdown clock to the July 30 deadline, and a new **Highest Score** column that replaces **Total Runs** and **Users Reached**.

### Updates

- **All publish paths now go through admin review** — The **Publish your agent** button is now **Submit for review** across all submission types, including bounty and requested-agent submissions.
- **Admin review cards** now display quality scores and detailed test run results.
- **Builder dashboard review status** is now simplified to **In review** without issue counts.
- **How it works guide link** is now available from the empty dashboard state and the publish page.

### Bug Fixes

- **Long-running test runs** no longer falsely report as failures when they take longer than 20 seconds to complete.
- **Session handling** now correctly refreshes dashboard queries so they do not use an outdated session.


</Update>
