## Overview

Gravity uses environment variables and configuration files across its three services. Each service reads its own `.env.example` file for local development, and deployment environments provide variables through infrastructure configuration. This page documents the key configuration options that affect runtime behavior.

<Callout kind="info">

Each service has its own `.env.example` file documenting available variables. Copy it to `.env` for local development. Variables marked as optional have sensible defaults and only need to be set when the corresponding feature is enabled.

</Callout>

## API service

### Core

- **`SUPABASE_URL`**: Supabase project URL. Required for normal API operation.
- **`SUPABASE_ANON_KEY`**: Supabase anon key. Required for some client paths.
- **`SUPABASE_SERVICE_ROLE_KEY`**: Privileged Supabase key for admin operations. Required for privileged API operations.
- **`PORT`**: API listening port. Optional. Default: `3001`.
- **`FRONTEND_URL`**: Public web origin for OAuth callbacks and redirects. Required for production OAuth.
- **`CORS_ORIGINS`**: Comma-separated allowed browser origins. Optional. Default: `http://localhost:3000,http://localhost:5173,http://localhost:5174`.
- **`AI_SERVICE_URL`**: Base URL for API-to-AI-service calls. Required for AI-service-backed features. Default: `http://localhost:8001`.
- **`AI_SERVICE_TIMEOUT_MS`**: Timeout for API-to-AI-service calls. Optional. Default: `10000`.

### LLM and AI credentials

- **`OPENROUTER_API_KEY`**: OpenRouter API key for LLM routing. Required for OpenRouter-backed features.
- **`GEMINI_API_KEY`**: Gemini API key for embeddings and AI features.
- **`OPENAI_API_KEY`**: OpenAI direct fallback. Optional.
- **`ANTHROPIC_API_KEY`**: Anthropic credential. Optional.
- **`COHERE_API_KEY`**: Cohere credential. Optional.
- **`COMPOSIO_API_KEY`**: Composio API key for tool integrations. Optional.

### Activepieces

- **`ACTIVEPIECES_INSTANCE_URL`**: Activepieces API URL. Required for workflow execution. Default: `http://localhost:8080`.
- **`AP_JWT_SECRET`**: Shared secret for minting Activepieces user JWTs. Required for Activepieces user provisioning.
- **`AP_POSTGRES_HOST`**: Activepieces Postgres hostname. Default: `localhost`.
- **`AP_POSTGRES_PORT`**: Activepieces Postgres port. Default: `5433`.
- **`AP_POSTGRES_DATABASE`**: Activepieces database name. Default: `activepieces`.
- **`AP_POSTGRES_USERNAME`**: Activepieces database user. Default: `activepieces`.
- **`AP_POSTGRES_PASSWORD`**: Activepieces database password. Required when Activepieces Postgres integration is enabled.
- **`GRAVITY_OAUTH_STATE_SECRET`**: Signs OAuth state JWTs. Falls back to `AP_JWT_SECRET`.

### Payments and billing

- **`RAZORPAY_KEY_ID` / `RAZORPAY_KEY_SECRET`**: Razorpay pay-in credentials. Required for Razorpay payments.
- **`RAZORPAY_WEBHOOK_SECRET`**: Razorpay webhook verification secret.
- **`RAZORPAYX_KEY_ID` / `RAZORPAYX_KEY_SECRET`**: RazorpayX payout credentials.
- **`RAZORPAYX_ACCOUNT_NUMBER`**: RazorpayX business virtual account.
- **`STRIPE_SECRET_KEY`**: Stripe server API key. Enables Stripe when present. Unset disables Stripe.
- **`STRIPE_PUBLISHABLE_KEY`**: Stripe browser key for checkout UI.
- **`STRIPE_WEBHOOK_SECRET`**: Stripe payment webhook signing secret.
- **`STRIPE_CONNECT_WEBHOOK_SECRET`**: Stripe Connect webhook signing secret.
- **`STRIPE_SUBSCRIPTIONS_WEBHOOK_SECRET`**: Subscription webhook signing secret.
- **`PAYMENTS_GEO_DEFAULT_COUNTRY`**: Fallback country for provider routing. Default: `IN`.
- **`PAYPAL_CLIENT_ID` / `PAYPAL_CLIENT_SECRET`**: PayPal payout credentials.
- **`PAYPAL_MODE`**: PayPal environment. Default: `sandbox`.

<Callout kind="info">

Billing enablement is controlled through the Supabase `pricing_config` table, not an environment variable. The `subscription_billing_enabled` flag controls whether subscription endpoints are active. The `subscription_enforcement_enabled` flag controls whether subscription admission blocks runs. Both flags are cached for 60 seconds and fail closed.

</Callout>

### OAuth broker

OAuth provider credentials use the dynamic names `OAUTH_<PROVIDER>_CLIENT_ID` and `OAUTH_<PROVIDER>_CLIENT_SECRET`. Each provider requires an independent credential pair. A missing pair makes that provider unavailable.

Common providers include Google, Slack, Notion, GitHub, Microsoft, HubSpot, Salesforce, Zoom, and Shopify.

### Notifications

- **`SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS`**: SMTP configuration for email notifications.
- **`MAIL_FROM`**: Sender email address.
- **`NOTIFICATIONS_ENABLED`**: Notification kill switch. Default: `true`.
- **`NOTIFICATIONS_REDIRECT_TO`**: Redirects all notification recipients for staging safety.

### Observability

- **`SENTRY_DSN` / `SENTRY_ENVIRONMENT`**: Sentry error tracking configuration.
- **`POSTHOG_API_KEY` / `POSTHOG_HOST` / `POSTHOG_ENVIRONMENT`**: PostHog analytics configuration.

## Web service

- **`VITE_SUPABASE_URL`**: Browser Supabase URL. Required for browser authentication.
- **`VITE_SUPABASE_ANON_KEY`**: Browser Supabase anon key. Required for browser authentication.
- **`VITE_API_URL`**: Base URL for browser API calls. Optional. Default: `/api`.
- **`VITE_APP_ENVIRONMENT`**: Controls development-only UI affordances. Set to `production` to hide development features.
- **`VITE_SENTRY_DSN` / `VITE_SENTRY_ENVIRONMENT`**: Browser Sentry configuration.
- **`VITE_POSTHOG_KEY` / `VITE_POSTHOG_HOST` / `VITE_POSTHOG_ENVIRONMENT`**: Browser PostHog configuration.
- **`VITE_CRISP_WEBSITE_ID`**: Crisp chat widget identifier.
- **`VITE_BUGFEED_PROJECT_ID`**: Bugfeed feedback widget project identifier.
- **`VITE_AP_TARGET`**: Vite proxy target for Activepieces. Default: `http://localhost:8080`.

<Callout kind="info">

Variables prefixed with `VITE_` are exposed to the browser. Do not store private credentials in these variables.

</Callout>

## AI service

### Core LLM

- **`OPENROUTER_API_KEY`**: OpenRouter API key. Required for chat, search, and recommendation features.
- **`OPENAI_API_KEY`**: OpenAI direct fallback. Required only when `OPENROUTER_API_KEY` is absent.
- **`OPENROUTER_INTENT_MODEL`**: Chat and intent model. Default: `anthropic/claude-sonnet-5`.
- **`OPENROUTER_RECOMMEND_MODEL`**: Recommendation model. Default: `anthropic/claude-sonnet-5`.
- **`ADMIN_API_TOKEN`**: Token for the `/admin/pricing` endpoint. Required only for that endpoint.

### Database and Redis

- **`SUPABASE_DATABASE_URL`**: SQLAlchemy database URL. Required unless component variables are provided.
- **`SUPABASE_DB_HOST` / `SUPABASE_DB_PORT` / `SUPABASE_DB_USER` / `SUPABASE_DB_PASSWORD` / `SUPABASE_DB_NAME`**: Component fallback variables for the database connection.
- **`REDIS_HOST`**: Redis hostname. Optional. Default: `localhost`.
- **`REDIS_PORT`**: Redis port. Optional. Default: `6379`.

### Gemini and search

- **`GEMINI_API_KEY`**: Gemini API key for embeddings and information retrieval generation. Required for embedding and indexing.
- **`TYPESENSE_API_KEY`**: Typesense API key. Required for agent search.
- **`TYPESENSE_HOST` / `TYPESENSE_PORT` / `TYPESENSE_PROTOCOL`**: Typesense connection settings. Defaults: `localhost`, `8108`, and `http`.

### Guardrail and AWS Bedrock

- **`BEDROCK_GUARDRAIL_ID`**: Bedrock guardrail ID. Required for active guardrail checks.
- **`AWS_REGION`**: AWS region. Default: `us-east-1`.
- **`AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY`**: AWS credentials.
- **`GUARDRAIL_FAIL_CLOSED`**: Controls behavior when guardrail checks fail. Default: `true`.

### Verification pipeline

The verification pipeline has tunable parameters with safe defaults.

- **`VERIFICATION_AUTO_REJECT_RISK`**: Automatic rejection threshold. Default: `85`.
- **`VERIFICATION_FLAG_RISK`**: Human-review flag threshold. Default: `70`.
- **`VERIFICATION_LLM_MODEL`**: Verification helper model. Default: `google/gemini-2.5-flash-lite`.
- **`VERIFICATION_AI_REVIEW_MODEL`**: Stronger reviewer model. Default: `google/gemini-2.5-flash`.

## Feature flags

| Flag | Location | Effect |
| --- | --- | --- |
| `subscription_billing_enabled` | Supabase `pricing_config` table | Enables subscription endpoints. Disabled by default. |
| `subscription_enforcement_enabled` | Supabase `pricing_config` table | Controls whether subscription admission blocks runs. Disabled by default. |
| `STRIPE_SECRET_KEY` present | Environment variable | Enables the Stripe payment provider. Unset disables Stripe. |
| `NOTIFICATIONS_ENABLED` | Environment variable | Acts as the email notification kill switch. Default: `true`. |
| `GUARDRAIL_FAIL_CLOSED` | Environment variable | Controls guardrail failure behavior. Default: `true`. |

<Callout kind="info">

The billing flags support shadow mode. Enable billing computation while keeping enforcement disabled to validate billing behavior before subscription admission blocks runs.

</Callout>

## Minimum production configuration

### API

```text
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
SUPABASE_ANON_KEY
PORT
FRONTEND_URL
CORS_ORIGINS
AI_SERVICE_URL
OPENROUTER_API_KEY
ACTIVEPIECES_INSTANCE_URL
AP_JWT_SECRET
```

### Web

```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
VITE_API_URL
VITE_APP_ENVIRONMENT=production
```

### AI service

```text
SUPABASE_DATABASE_URL
OPENROUTER_API_KEY
GEMINI_API_KEY
TYPESENSE_API_KEY
TYPESENSE_HOST
TYPESENSE_PORT
TYPESENSE_PROTOCOL
```

Add payment, notification, observability, and guardrail variables based on the features enabled for the deployment.
