## Overview

This changelog tracks notable platform updates, improvements, and fixes. Entries are verified against merged pull requests before publication.

## Release history

<Update label="2026-07-01" description="Platform update" tags={["feature", "improvement", "bugfix"]}>

### Platform

- **Manual trigger support**: Workflows using Activepieces' Manual Trigger piece can now be published and run as on-demand agents. Manual-trigger agents present a single `Run` button with no webhook URL, and tagged inputs are baked into the flow directly.
- **Telemetry API**: New unauthenticated endpoints `GET /api/telemetry/loading-durations` and `POST /api/telemetry/loading-durations` track rolling-average durations for loading phases including analyzing, connecting, deploying, and executing. Durations are clamped to `50ms` through `600,000ms`.
- **Credit estimation from test runs**: The publish flow now seeds credit-per-run estimates from the measured LLM cost of a pre-publish test run instead of relying only on structural node-count estimates.
- **Bookmarkable dashboard sessions**: Dashboard conversations are now encoded in the URL as `?session=<id>`. Refreshing the page or navigating back restores the correct conversation without a flash.
- **Subscription card enrichment**: Subscription-mode agent cards now display workflow steps, credits per run, and the next scheduled run time.

### Improvements

- **OAuth connection flow**: The authorization popup now closes immediately after the provider returns, with a new `Finalizing…` button state during the backend token exchange. Connection errors are verified by polling before the UI declares failure, which helps recover from lost responses.
- **Humanized connection errors**: Connection failure messages now display clear, actionable sentences instead of raw API error dumps.
- **Real-time progress indicators**: Loading progress rings and bars now use learned rolling-average durations from telemetry data instead of fixed estimates. Per-agent execution times are seeded from the publish test run.
- **Loading text updates**: Connecting phases now show `Setting up your agent…` and `Checking your connected tools…` instead of idle text.
- **Draft review layout**: The draft review card footer is unified across one-time and recurring agents, with an `Execute again` option for completed runs.
- **Workflow step reordering**: The agent builder's `How it works` steps now support drag-and-drop and keyboard reordering.
- **Connect more tools shortcut**: The `Connect more tools` action on the no-agents-found card now navigates directly to the apps page.
- **Sidebar navigation**: The sidebar no longer re-animates on route navigation.

### Fixes

- **App webhook triggers**: App webhook trigger strategies are now correctly recognized during workflow introspection. Previously, a naming mismatch caused them to be silently rejected.
- **Conversation deletion**: Deleting the currently active conversation now resets to a fresh chat instead of leaving a stranded view.
- **Connection setup instructions**: Markdown formatting including bold text, links, and lists in connection setup instructions now renders correctly instead of appearing as raw monospaced text.


</Update>
