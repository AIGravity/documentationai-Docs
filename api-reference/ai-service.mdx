## Overview

The Gravity AI service is a FastAPI application that handles conversational interaction, agent verification, quality review, content generation, and usage metering. The NestJS API delegates AI-related work to this service over HTTP. Most endpoints are internal, called by the API rather than directly by users, and rely on network-level access controls instead of service-level authentication.

<Callout kind="info">

Endpoints prefixed with `/internal` are intended for service-to-service calls from the NestJS API and are not exposed to end users. User-facing interactions are proxied through the API.

</Callout>

## Health

### GET `/health`

Check AI service liveness. The response includes service status, version, and chat availability.

No authentication is required.

<ResponseField name="status" field-type="string" required="true">

Health state. The current implementation returns `healthy`.

</ResponseField>

<ResponseField name="service" field-type="string" required="true">

AI service name.

</ResponseField>

<ResponseField name="version" field-type="string" required="true">

Service version.

</ResponseField>

<ResponseField name="chat_available" field-type="boolean" required="true">

Whether the chat pipeline is ready.

</ResponseField>

## Chat and intent detection

### POST `/chat`

Run the conversational pipeline, including guardrails, session handling, intent detection, response generation, tool suggestions, and agent search.

No service-level authentication is required. The request must include `user_id` and `session_id`.

<ParamField body="user_id" param-type="string" required="true">

UUID identifier for the user.

</ParamField>

<ParamField body="session_id" param-type="string" required="true">

UUID identifier for the chat session.

</ParamField>

<ParamField body="message" param-type="string" required="true">

User message, limited to 4,000 characters.

</ParamField>

<ParamField body="selected_tools" param-type="array">

Selected integration or tool identifiers.

</ParamField>

<ParamField body="submit_tools" param-type="boolean">

Whether the request submits a tool selection.

</ParamField>

<ParamField body="agent_id" param-type="string" required="false">

Agent context for the conversation.

</ParamField>

The response includes the following fields:

<ResponseField name="reply" field-type="string">

Assistant reply text.

</ResponseField>

<ResponseField name="session_id" field-type="string">

Chat session identifier.

</ResponseField>

<ResponseField name="question" field-type="string">

Clarification question when the pipeline needs more information.

</ResponseField>

<ResponseField name="options" field-type="array">

Options presented for a clarification question.

</ResponseField>

<ResponseField name="mode" field-type="string">

Current interaction mode.

</ResponseField>

<ResponseField name="info_json" field-type="object">

Structured intent data, including agent type, platforms, tools, and use case.

</ResponseField>

<ResponseField name="ready_to_query" field-type="boolean">

Whether the pipeline has gathered enough information to search for agents.

</ResponseField>

<ResponseField name="top_agents" field-type="array">

Recommended agents when search results are available.

</ResponseField>

<ResponseField name="suggested_tools" field-type="array">

Recommended tools for the conversation.

</ResponseField>

<Callout kind="info">

Intent detection and agent search are stages within the `/chat` pipeline, not separate endpoints.

</Callout>

</ParamField>

<ParamField body="source" param-type="string" enum="INPUT,OUTPUT">
