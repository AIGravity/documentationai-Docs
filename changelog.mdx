## Recent release

<Update label="Recent" description="Recent release" tags={["feature", "improvement", "bugfix"]}>

### New features

- **India-based builders can receive earnings** through bank transfer or UPI.
- **Chat supports more flexible exploration** and shows selectable options when they help you choose a direction.

### Updates

- **Subscription usage is clearer**, including estimated runs, capacity reserved for scheduled automations, and renewal status.
- **The builder workspace is easier to navigate**, with a clearer path for customizing your work.

### Bug fixes

- **Marketplace automations handle approval pauses and workflow compatibility more reliably.**
- **Automation errors provide clearer next steps** when a run cannot continue.
- **Long-running automation runs are less likely to be reported as failures by mistake.**

</Update>
