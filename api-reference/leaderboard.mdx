## Retrieve the public builder leaderboard

Retrieve a ranked public leaderboard of builders with total earnings and published agent counts. This endpoint is public and does not require authentication.

<Callout kind="info">

Send this request without an `Authorization` header. The API returns public leaderboard data only.


</Callout>

### GET `/api/leaderboard/builders`

Returns builders ordered by rank, including earnings and published agent totals.

<ParamField query="limit" param-type="integer" required="false">

Maximum number of builders to return. Defaults to `100`. Minimum value is `1`. Maximum value is `200`.

</ParamField>

### Example request

<CodeGroup tabs="cURL,JSON response">

```bash
curl -X GET "http://localhost:3001/api/leaderboard/builders?limit=5"
```

### Response fields

<ResponseField name="builderId" field-type="string" required="true">

Unique builder identifier.

</ResponseField>

<ResponseField name="builderName" field-type="string" required="true">

Public display name of the builder.

</ResponseField>

<ResponseField name="rank" field-type="number" required="true">

Builder position in the leaderboard, starting at `1`.

</ResponseField>

<ResponseField name="totalEarnings" field-type="number" required="true">

Total earnings attributed to the builder.

</ResponseField>

<ResponseField name="agentsPublished" field-type="number" required="true">

Number of published agents owned by the builder.

</ResponseField>
