## Latest release

<Update label="Latest" description="Gravity foundation release" tags={["feature", "update"]}>

### New features

- **Web app shell launched** — Gravity now has a visible Remix-based web experience that loads a starter screen and establishes the user-facing app surface. See [Quickstart](/quickstart) and [Frontend Application Shell](/frontend-application-shell).
- **System dark-mode support** — The web experience adapts to the visitor's operating-system color preference, including the page background and visible brand assets. See [Frontend Application Shell](/frontend-application-shell).
- **API health check available** — The API service now exposes a lightweight health response for confirming the service is reachable during local setup and deployment checks. See [Health Checks](/health-checks).
- **AI service health check available** — The AI service now exposes its own health response so teams can verify that the service is running independently. See [Health Checks](/health-checks).

### Updates

- **Service release and versioning flow available** — Web, API, and AI services now have service-level release/versioning support for tracking independently shipped foundations. See [Service Versioning](/service-versioning).

No user-facing bug fixes were verified for this release.

</Update>
