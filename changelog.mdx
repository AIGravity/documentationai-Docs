## Release history

<Update label="Initial release" description="Foundations for versioning, delivery, and the web app" tags={["feature", "improvement", "bugfix"]}>

### New features

- Added per-service semantic versioning with automatic CI detection and manual bump workflows. See [Service versioning](/service-versioning).
- Added CI/CD pipelines for the web, API, and AI services that publish Docker images and GitHub releases. See [CI/CD pipelines](/ci-cd-pipelines) and [Docker images and packaging](/docker-images-and-packaging).

### Updates

- Migrated the web app from React Router v7 to Remix v2.
- Upgraded the web app styling stack to Tailwind CSS v4.

### Bug fixes

- Fixed the web service Docker build so production image builds complete successfully.

</Update>
