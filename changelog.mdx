## v0.1.0 — March 7, 2026

Initial release of all platform services.

### New Features

- **Service versioning** — All services now track their own version numbers, starting at v0.1.0. Versions bump automatically based on commit type. See [Service Versioning](/service-versioning).
- **Automated CI/CD pipelines** — Each service now builds, versions, and deploys automatically through CI pipelines. See [CI/CD Pipelines](/ci-cd-pipelines).

### Updates

- **Web app migrated to Remix v2** — The frontend now runs on Remix v2, replacing the previous routing framework. This brings improved routing and faster page loads.
- **Tailwind CSS upgraded to v4** — The web app's styling system is now powered by Tailwind CSS v4, with the latest design utilities and improved build performance.

### Bug Fixes

- **Fixed container build failure** — Resolved an issue where the web application's container builds failed due to a missing shared configuration file.
