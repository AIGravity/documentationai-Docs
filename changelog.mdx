## Overview

This changelog tracks reader-facing releases across the Gravity platform and documentation. Entries are ordered newest first and grouped by change type.

## Release history

<Update label="2026-03-07" description="v0.1.0" tags={["feature", "improvement"]}>

### New features

- Added CI/CD pipelines for the AI service, API service, and web app. Each service now builds independently in GitHub Actions.
- Added per-service semantic versioning. Each service now tracks and tags its own release version.
- Added Docker container images for all three services. Images now build and publish through the service pipelines.

### Updates

- Migrated the web app to Remix and adopted Tailwind CSS v4. The frontend now builds and serves through the Remix application shell.

</Update>

## How to read this changelog

Scan from top to bottom when you want the newest information first. Read New features first, then Updates for delivery or platform changes that affect how Gravity is built and shipped.
