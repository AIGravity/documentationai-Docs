## Release history

<Update label="2026-03-15" description="March 2026 platform updates" tags={["feature", "improvement"]}>

### New features

- **Per-service semantic versioning** now uses a `VERSION` file for each service and a dedicated version-bump workflow. Version changes apply independently to the web app, API, and AI service. See [Service Versioning](/service-versioning).
- **CI/CD pipelines** now run as separate workflows for the web app, API, and AI service. Each pipeline builds, versions, publishes, and deploys its own service. See [CI/CD Pipelines](/ci-cd-pipelines).
- **Docker image publishing** now pushes service images to GitHub Container Registry for the web app, API, and AI service. See [Docker Images and Packaging](/docker-images-and-packaging).

Use the root helper scripts to bump a single service version when you need a manual release step.

```bash
pnpm version:web:patch
pnpm version:api:minor
pnpm version:ai:major
```

### Updates

- **Web frontend migration** moved the frontend to Remix v2 and Tailwind CSS v4. The app shell, build flow, and styling pipeline now follow that stack. See [Frontend Application Shell](/frontend-application-shell).

</Update>
