## Release history

<Update label="2026-07-03" description="July 3, 2026" tags={["bugfix"]}>

### Bug fixes

- **Agent search returns more precise results.** The relevance threshold for agent recommendations has been tightened, filtering out loosely related matches. You'll now see fewer results, but each one is more closely aligned with your query. Suggested tools are also more on-topic as a result. See [AI Service Foundation](/ai-service-foundation) and the [AI Service API](/api-reference/ai-service) for details.


</Update>
