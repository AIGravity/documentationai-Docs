## Overview

This page documents the NestJS backend service routes currently implemented in the AIGravity core repository. The code analysis found two endpoint groups: the health check endpoint `GET /health`, and the builder profile endpoints `GET /builders/me` and `PATCH /builders/me`.

<Callout kind="info">

Implementation details on this page were derived from code analysis of `apps/api/src/main.ts`, `apps/api/src/app.module.ts`, and `apps/api/src/health/health.controller.ts`, rather than direct file reads through the docs repository tool.


</Callout>

<Callout kind="alert">

The repository README mentions `GET /api/health`, but the code currently implements `GET /health`. No global prefix is configured, so the `/api` path is not active.


</Callout>

## Likely error responses

The analyzed code does not define custom error handling for this route. The most likely responses are framework-level errors.

### 404 not found

A `404` response is likely when you request the wrong path or use the wrong HTTP method. For example, `GET /api/health` or `POST /health` would not match the implemented route.

### 500 internal server error

A `500` response is only likely if the NestJS framework or runtime fails while serving the request. No route-specific error branches were found in the analyzed handler.

## Notes

The NestJS bootstrap code enables CORS for origin `http://localhost:3000` and sets `credentials` to `true`. The application listens on port `3001`, so the health endpoint is available at `http://localhost:3001/health` in the current local configuration.

## Builder profile endpoints

These endpoints return and update the authenticated builder profile. Both endpoints also return lifetime earnings derived from the `creator_earnings_ledger` table.

### GET `/builders/me`

Use this endpoint to fetch the authenticated builder's profile, including lifetime earnings derived from the `creator_earnings_ledger` table. The `totalEarnings` field is a legacy column that always returns `0`; use `lifetimeEarningsCredits` and `lifetimeEarningsUsd` for actual earnings data.

<ParamField body="method" param-type="string" required="true" show-location="false">

`GET`


</ParamField>

<ParamField body="path" param-type="string" required="true" show-location="false">

`/builders/me`


</ParamField>

<ParamField body="auth" param-type="string" required="true" show-location="false">

Requires authentication. The builder is identified from the authenticated user's session or token.


</ParamField>

#### Request details

This endpoint does not accept request-specific inputs beyond the authenticated `GET` request.

##### Path parameters

<ParamField body="path parameters" param-type="none" required="false" show-location="false">

None. The route is fixed at `GET /builders/me`.


</ParamField>

##### Query parameters

<ParamField body="query parameters" param-type="none" required="false" show-location="false">

None. The handler does not define or consume query string values.


</ParamField>

##### Headers

<ParamField body="custom headers" param-type="none" required="false" show-location="false">

None beyond standard authentication headers.


</ParamField>

##### Request body

<ParamField body="request body" param-type="none" required="false" show-location="false">

None. `GET /builders/me` does not accept a request body.


</ParamField>

<CodeGroup tabs="cURL">

```bash
curl -i http://localhost:3001/builders/me \
```

#### Response

A successful request returns the authenticated builder profile and the current lifetime earnings projection.

<CodeGroup tabs="JSON">

```json
{
  "userId": "usr_abc123",
  "currency": "USD",
  "totalEarnings": 0,
  "lifetimeEarningsCredits": 2450,
  "lifetimeEarningsUsd": 24.50,
  "createdAt": "2026-01-15T10:30:00.000Z",
  "updatedAt": "2026-06-30T14:20:00.000Z"
}
```

</CodeGroup>

##### Response fields

<ResponseField name="userId" field-type="string" required="true">

Unique identifier for the builder user.


</ResponseField>

<ResponseField name="currency" field-type="string" required="true">

Display currency code for the builder's earnings, such as `USD`, `EUR`, or `GBP`.


</ResponseField>

<ResponseField name="totalEarnings" field-type="number" required="true" deprecated="true">

Legacy earnings column. Always returns `0`. No code path writes to this field. Use `lifetimeEarningsCredits` and `lifetimeEarningsUsd` instead.


</ResponseField>

<ResponseField name="lifetimeEarningsCredits" field-type="integer" required="true">

Total credits earned by the builder, summed from the `creator_earnings_ledger` table. The total includes positive earnings and negative refund reversals. `1` credit equals `$0.01`.


</ResponseField>

<ResponseField name="lifetimeEarningsUsd" field-type="number" required="true">

Lifetime earnings in USD, computed as `lifetimeEarningsCredits` divided by `100`.


</ResponseField>

<ResponseField name="createdAt" field-type="string" required="true">

ISO 8601 timestamp when the builder profile was created.


</ResponseField>

<ResponseField name="updatedAt" field-type="string" required="true">

ISO 8601 timestamp when the builder profile was last updated.


</ResponseField>

#### Error responses

##### 401 unauthorized

A `401` response indicates that authentication is required or the supplied token is invalid.

##### 404 not found

A `404` response indicates that no builder profile exists for the authenticated user.

##### 500 internal server error

A `500` response indicates an unexpected server error. If the `creator_earnings_ledger` table is unavailable, the endpoint falls back to `lifetimeEarningsCredits` of `0` instead of failing the request.

##### Path parameters

<ParamField body="path parameters" param-type="none" required="false" show-location="false">

<Callout kind="info">

The `PATCH` endpoint delegates to the same response path as `GET /builders/me` after applying the update, so the response always includes current lifetime earnings from the `creator_earnings_ledger` table. The legacy `totalEarnings` field is retained for backward compatibility but is never populated; it always returns `0`.


</Callout>
