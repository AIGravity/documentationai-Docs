## Overview

This changelog tracks notable product changes — new features, updates, and bug fixes — shipped to the platform.

## Release history

<Update label="Latest" description="Current release" tags={["feature", "bugfix"]}>

### New features

- **Video walkthrough on the docs overview page.** A video walkthrough is now embedded at the top of the in-app docs overview, giving new users a quick visual tour of the platform and its core workflows. See [Features](/features) for a written overview of platform capabilities.

### Bug fixes

- **Fixed sign-up failures for names containing dots or slashes.** Users whose full name contained dots or slashes, or who had no display name set, causing a fallback to their email address, could encounter errors during account provisioning. Names are now sanitized before sign-up, so provisioning completes successfully regardless of name format.

- **Fixed incorrect credit costs on rejected and pending agent reviews.** Review traces created during automated checks could display a credit cost of zero in certain states, including gate-failure rejections, abandoned submissions, and admin-archived reviews. Credit costs are now calculated when a review trace is created, ensuring accurate cost figures across all review states.



</Update>
