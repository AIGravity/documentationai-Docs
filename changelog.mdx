## Release history

<Update label="2026-03-15" description="CI/CD, versioning, frontend, and packaging updates" tags={["feature", "improvement"]}>

### New features

- Added CI/CD pipelines for the web, API, and AI services. See [CI/CD Pipelines](/ci-cd-pipelines).
- Added per-service semantic versioning with independent release flow for each service. See [Service Versioning](/service-versioning).

### Updates

- Migrated the frontend shell to Remix v2. See [Frontend Application Shell](/frontend-application-shell).
- Upgraded the frontend styling stack to Tailwind CSS v4. See [Frontend Application Shell](/frontend-application-shell).
- Simplified web Docker packaging and image build flow. See [Docker Images and Packaging](/docker-images-and-packaging).

- No bug fixes shipped in this batch.
