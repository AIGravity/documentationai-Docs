## Overview

This changelog tracks notable API endpoint changes, data model updates, and deprecated endpoint migrations in the AIGravity platform.

## Release history

<Update label="2026-06-28" description="API changes" tags={["feature", "breaking", "improvement"]}>

### API endpoint consolidation and dynamic dropdown support

**Added endpoints:**

- `POST /api/connections/auth/apps` — List Composio apps referenced in a workflow (migrated from legacy `n8n-workflow` path).
- `POST /api/connections/auth/initiate` — Initiate Composio OAuth connection (migrated from legacy path).
- `POST /api/connections/auth/status` — Check Composio connection status (migrated from legacy path).
- `GET /api/connections/auth/connections` — List all user connections with normalized statuses (migrated from legacy path).
- `POST /api/connections/auth/disconnect` — Disconnect a Composio app (migrated from legacy path).
- `POST /api/marketplace/builder-fields` — Resolve builder fields from consumer inputs for a published workflow.
- `DELETE /api/apps/pending/all` — Bulk-clear all pending apps from the user's wishlist.

**Modified behavior:**

- `POST /api/marketplace/property-options` now auto-detects `actionOrTrigger` from the flow node and derives piece coordinates from the live flow, fixing stale version errors that caused HTTP 400 from ActivePieces.
- `POST /api/marketplace/test-builder/run` now publishes and runs the flow as `ENABLED` before testing, then disables it after the run completes. A new `500` error is returned when no run result is produced.
- `POST /api/agents/publish-agent` now enriches consumer inputs with refreshers, cascade context, static options, and default values. New `array` and `dynamic-cascade` field types are supported. `creditCost` is now estimated from workflow AI node count when not explicitly provided.

**New data model fields:**

- `ConsumerInput.targets` — Binds a consumer input to multiple workflow node parameters simultaneously.
- `ConsumerInput` type now includes `array` — Supports repeated-value inputs with comma- or newline-separated string splitting.
- `BuilderFieldWireShape.targets` — Array of `nodeName` and `paramPath` mappings for field-to-node binding.

**Deprecated endpoints:**

All `POST` and `GET` routes under ` /api/n8n-workflow/* ` and all `POST` routes under ` /api/inngest-trigger/* ` have been removed and marked as deprecated. Calling any deprecated endpoint returns `410 Gone`. See the [NestJS API reference](/api-reference/nestjs-api#deprecated-endpoints) for the full migration table.


</Update>
