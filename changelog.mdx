## September 2026

Gravity's September 2026 release adds version-aware integrations, agent review improvements, monetization foundations, and clearer workflow operations.

<Update date="September 2026" title="September 2026">

### New Features

- **Version-aware Activepieces compatibility:** Gravity now detects your Activepieces instance version and adapts its compatibility behavior automatically. Activepieces upgrades no longer need to ship in lockstep with Gravity releases. See [Integrations](/integrations).
- **Agent review with evidence scoring:** Agent reviews now include memory analysis and evidence-based scoring, giving reviewers richer context when evaluating agent quality.
- **Billing and monetization foundations:** Subscription plans, creator payouts, and referral earnings are now available as the foundation for monetizing agents on the marketplace.

### Updates

- **Paused-run clarity:** Paused workflow runs now show whether they are waiting for approval, a scheduled delay, or an agent-driven pause, so you can identify the required action at a glance.
- **Clearer workflow error messages:** Failures from timeouts, memory limits, log-size limits, and quota issues now surface the underlying Activepieces message instead of a generic error.
- **File proxy security:** File proxying is now restricted to Gravity's own Activepieces host, preventing requests to untrusted destinations.
- **Automatic production deploys:** Pushing to the main branch now deploys all services to production automatically, reducing manual deployment steps.

### Bug Fixes

- **Production AI service URL:** Fixed an issue where production API calls used the non-production AI service URL, affecting chat, guardrails, and marketplace builder tests in production.
- **Activepieces database tunnel:** Fixed a deployment issue where the Activepieces Postgres tunnel hostname rendered empty, temporarily blocking API access to the Activepieces database.
- **Web build in clean CI:** Fixed a build failure caused by a required TypeScript configuration file missing from the Docker build context.

</Update>
