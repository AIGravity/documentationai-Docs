## Overview

Track notable product changes with each release. The newest entries appear first.

<Update label="2026-07-04" description="Product update">

### New Features

- **EUR and GBP credit purchases** — Credit packages can now be purchased in Euros or Pounds Sterling. Package prices are calculated at live exchange rates from the USD base price. Select your preferred currency in Settings or at checkout.
- **Real builder earnings** — The builder dashboard's per-agent earnings column and the agent details revenue card now display actual revenue from the transaction ledger, shown in your preferred currency. Previously, these always displayed ₹0 or $0.
- **Disconnect and reconnect apps from Settings** — The Connected Apps tab in Builder Settings now shows the real connection state of each app. You can disconnect an app directly and reconnect it through the proper authentication flow. Previously, the tab showed stale "Reconnect" buttons on apps that were already connected, with no way to disconnect. See [Integrations](/integrations) for more on supported apps.

### Updates

- **Chat sessions are now URL-driven** — Each conversation is tied to its URL. Opening a fresh dashboard always starts a brand-new chat, and the new chat appears instantly in the sidebar as soon as you send your first message. No more waiting for a page reload to see it appear.
- **Marketplace question cards show the right text** — When interacting with a marketplace agent, question cards now display the builder's actual question as the title, with any helper text shown as a smaller description below it. Previously, the builder's description was incorrectly shown as the question title.
- **Faster on-demand agent runs** — On-demand marketplace agent runs are now up to 2 seconds faster and use fewer backend calls.
- **On-demand runs count toward builder stats** — On-demand executions were previously invisible to the builder's run counter. They now count correctly toward your published agent's run statistics.

### Bug Fixes

- **Fixed chat session bleed** — Starting a new chat no longer silently continues your previous conversation. Logging out and signing in as a different user no longer carries over the previous user's chat history.
- **Fixed credit misattribution on concurrent runs** — When running the same agent concurrently, credits are now correctly charged to the right run instead of potentially being attributed to the wrong one.
- **Fixed builder earnings page for creator accounts** — Accounts that published agents but were typed as "creator" no longer receive an error when viewing their earnings. The "Total earnings" card on the builder dashboard is also no longer a dead link for these accounts.


</Update>
