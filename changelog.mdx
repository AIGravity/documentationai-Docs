## Release history

<Update label="2026-03-15" description="v0.1.0" tags={["feature", "improvement"]}>

### New features

- **Semantic versioning system** — Services now follow independent semantic versioning with clear release increments. See [Service versioning](/service-versioning).
- **Per-service GitHub releases** — Web, API, and AI services now publish separate release tags and notes. See [CI/CD pipelines](/ci-cd-pipelines).

### Updates

- **Frontend migration to Remix v2** — The frontend runtime now uses Remix v2. See [Frontend application shell](/frontend-application-shell).
- **Tailwind v4 upgrade** — The frontend styling stack now uses Tailwind v4. See [Frontend application shell](/frontend-application-shell).
- **Refined web Docker packaging** — Web image packaging is now cleaner and more consistent for build and runtime delivery. See [Docker images and packaging](/docker-images-and-packaging).

### Bug fixes

- None in this release.

</Update>
