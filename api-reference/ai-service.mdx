## Overview

The AI service is a FastAPI application running on port 8001. It provides chat interactions, content guardrails, text embeddings, agent verification, agent review, and credit metering.

Most endpoints require no authentication. Internal service-to-service endpoints use the `/internal` path prefix. See the [OpenAPI specification](/api-reference/openapi) for complete request and response schemas.

No authentication is required.

## Chat

### POST /chat

Send a message to an AI chat session and receive an interaction response.

No authentication is required.

<CodeGroup tabs="cURL,JSON response">

```bash
curl -X POST http://localhost:8001/chat \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "8f7c2d61-4dd2-4b5c-9a4e-0e4b9f0c3d21",

    "message": "Summarize the latest workflow results",
    "selected_tools": ["workflow_search"],
    "submit_tools": true,
    "agent_id": "agent_workflow_summary"

```

  "session_id": "c5e2b1d7-9f2a-4e73-8b6c-7d1a5f3e2c90",

## Embedding and indexing

### POST /internal/embed

Generate a vector embedding for text. This service-to-service endpoint does not require authentication.

<CodeGroup tabs="cURL,JSON response">

```bash
curl -X POST http://localhost:8001/internal/embed \
  -H "Content-Type: application/json" \
  -d '{
    "text": "A workflow that summarizes customer support conversations"
  }'
```

```json
{
  "embedding": [0.0124, -0.0831, 0.2047],
  "dims": 768
}
```

</CodeGroup>

<ParamField body="text" param-type="string" required="true" show-location="false">

Text to embed. The length must be between 1 and 20,000 characters.

</ParamField>

<ResponseField name="embedding" field-type="number[]" required="true">

Generated embedding vector.

</ResponseField>

<ResponseField name="dims" field-type="integer" required="true">

Number of dimensions in the embedding vector.

</ResponseField>

The endpoint returns `422 Unprocessable Entity` for invalid text, `503 Service Unavailable` when `GEMINI_API_KEY` is not configured, and `502 Bad Gateway` when embedding generation fails.

## Common error responses

The service uses these error codes across multiple endpoint groups:

| Status | Meaning |
| --- | --- |
| `422 Unprocessable Entity` | Pydantic validation failed for the request path, query, header, or body. |
| `502 Bad Gateway` | An upstream language model or embedding provider failed while generating a result. |
| `503 Service Unavailable` | A required language model key or Gemini API key is not configured. |
| `403 Forbidden` | The admin token is missing or incorrect. |
| `404 Not Found` | The requested resource does not exist. |

<Callout kind="info">

Some endpoints intentionally return error-shaped HTTP 200 responses. Check the response body for `indexed: false` on agent indexing, `deleted: false` on agent deletion, and the endpoint-specific result fields for verification generation and Composio compatibility responses.

</Callout>

For complete schemas, including nested request and response models, see the [OpenAPI specification](/api-reference/openapi).
