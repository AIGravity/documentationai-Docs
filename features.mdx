## Overview

The Gravity platform is an AI-agent and workflow marketplace. It provides conversational agent discovery, an agent marketplace with publishing and verification, billing with subscriptions and credits, agent quality review, bounties for builder community contributions, and ActivePieces-powered workflow execution.

## How it fits together

The chat interface helps users discover agents through conversational AI. Builders publish agents through a verification pipeline. Consumers browse the marketplace, connect required tools, and run agents. Billing tracks per-run charges against credit balances or subscription entitlements. Creators earn from their agents and can receive payouts. The agent review system provides quality assurance alongside the verification gates.
