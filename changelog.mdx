## July 18, 2026

### New Features

- **In-app documentation center** — A new `/docs` page is available in the product with multi-page guides covering the workflow engine, supported integrations, AI capabilities, publishing, and more. "How it works" links throughout the product now point here instead of an external page.
- **AI-generated agent metadata** — When you upload a workflow, AI automatically writes the title, description, and problem-solved fields for your agent. No manual button press needed — fields are filled in instantly and ready to edit. See [Features](/features) for an overview of agent capabilities.

### Updates

- **Smarter chat conversations** — The chat assistant is more context-aware and conversational. It no longer forces you to name a specific platform before proceeding, has a friendlier tone, and shows tappable option chips more consistently.
- **Better help during tool selection** — If you ask "what does that mean?" while picking tools, the chat now explains what tools are and keeps the picker open so you can continue.
- **Improved "no agent found" messaging** — When no matching agent is found, the chat now suggests requesting a custom agent through the bounty flow.
- **Tighter agent search results** — Agent matching is now stricter, reducing irrelevant results in chat conversations.
- **Publish Gate temporarily lifted** — Due to an upstream package installation issue, the Publish Gate requirement is temporarily disabled so builders can submit agents without it. The in-app docs provide an alternative install script as a workaround.

### Bug Fixes

- **Empty results carousel** — Fixed an issue where the chat could display an empty "Top matches" carousel when all search results pointed to unpublished agents.
- **Agent builder edit tracking** — Edits made to AI-generated fields are now properly captured when publishing or submitting for review.

## How to read this changelog

Entries are organized newest first. Each release is split into **New Features**, **Updates**, and **Bug Fixes** so you can scan for what matters to you.
