## Overview

The Gravity frontend is a Remix application that provides the full product experience for consumers, builders, reviewers, and administrators. It connects to the NestJS API through authenticated REST requests and renders agent discovery, execution, billing, creator economics, and administrative workflows.

## Paused-run display

The frontend renders paused executions with messaging that matches the pause kind:

- **`approval`**: Shows an approval step waiting for a human decision.
- **`delay`**: Shows a timer or wait period.
- **`agent`**: Shows an AI-agent waitpoint.
- **`unknown`**: Shows a generic wait message.

## Execution output rendering

The frontend renders marketplace run results across multiple output types:

- Text output
- Files and downloadable content
- Images
- PDFs
- Structured values
- Step-by-step outputs

## Connection management

Users manage external tool connections through:

- OAuth authorization flows, including Gravity-managed or custom credentials
- API key entry
- Activepieces connections
- Connection health and status display

## Dynamic consumer input forms

The frontend renders dynamic input forms that adapt to each agent's requirements:

- Text fields
- Date fields
- File uploads
- Dropdown selections
- Cascade selections
- Array inputs
- JSON inputs
- Schedule configuration

## Build and packaging

The frontend builds with Remix, Vite, and Tailwind CSS. It runs on port `3000` in development and can be containerized with Docker for production deployment.

<Callout kind="tip">

The frontend communicates with the API on port `3001`. CORS is configured to allow requests from the frontend origin.

</Callout>
