## Release history

1. **Unreleased — Ranker Score Enrichment**
   - **Enhancements**
     - Agent quality scores now retain the complete scoring breakdown, including per-dimension scores (quality, reliability, speed, cost), posterior estimates, and failure indicators. Previously, only a trimmed subset was stored.
     - Agent review submissions now incorporate verification history — including gate decisions, verification attempt count, and AI review outcomes — as scoring inputs, producing more accurate initial quality scores for newly submitted agents.
   - **Fixes**
     - Cost-based quality scoring is now active for all agent submissions. Previously, submissions without an explicit credit cost (such as E2E test submissions) were scored without the cost dimension, which could lower overall score accuracy.
