## Overview

Track user-facing product updates here, with the newest releases listed first. Each entry highlights what changed and what it means for administrators, creators, and teams using the marketplace.

## Releases

<Update label="June 2025" description="Marketplace billing: admin dashboard + minimum creator payout" tags={["feature", "improvement"]}>

### New Features

- **Marketplace billing admin dashboard** — Administrators can now view marketplace billing activity, credit usage, and creator earnings from a centralized dashboard. This replaces manual tracking with real-time visibility into billing data.
- **Minimum creator payout threshold** — Creators now only receive payouts once their earnings reach a configurable minimum amount. This reduces transaction overhead and ensures payouts are meaningful. See the [Configuration Reference](/configuration-reference) for payout settings.

### Updates

- **Metered credit usage tracking** — Credit usage is now metered and tracked across marketplace transactions. This provides the data foundation for the billing dashboard and payout calculations.

### Bug Fixes

- **No user-facing bug fixes** — This release does not include user-facing bug fixes.


</Update>
