<Update date="2026-09-10">

### New features

- **Agent review pipeline** — Admins can now test-run submitted agents before approving them. Test output appears in plain language instead of raw JSON, and automated quality checks cover data flow, control flow, reliability, and grounding. Admins can edit, approve, reject, and send targeted feedback to builders. Builders can respond with thumbs-up/down and rebuttals on individual findings. See [Features](/features).
- **Runtime safety checkpoints** — Before an agent performs an external action, each outside-world step can be allowed, paused for user input, blocked, or safely failed closed if the safety checker is unreachable. Checkpoints cover nested structures including routers, loops, and branches. See [Features](/features).
- **Activepieces version compatibility** — Gravity now auto-detects the connected Activepieces version and applies compatibility workarounds automatically, enabling safer upgrades without coordinated deployments. See [Integrations](/integrations).

### Updates

- Marketplace failure messages now explain whether the problem is with the platform, a connection, the workflow, or a missing setup answer — instead of showing a generic error.
- Expensive AI models are automatically capped by price and replaced with a suitable lower-cost alternative from the same vendor.
- Long-running marketplace executions no longer lose the browser session or charge incorrectly.
- Paused runs are now distinguished by type — approval, timer, or agent — with clear, kind-aware messaging in the UI.

### Bug fixes

- Fixed production API routing that was sending requests to the non-production AI service, affecting chat, guardrails, and marketplace test-builder runs.
- Agent submissions containing stray NUL characters no longer fail with misleading database errors.
- Empty Activepieces option responses now produce readable errors instead of JSON parsing failures.
- Approval-based agents no longer appear as failed while awaiting approval — they now show as in-progress with the pending step visible.
- Flow cleanup no longer disables a flow while an approval is still pending.
- Recurring-agent polling now preserves paused runs across transient errors and retries.

</Update>
