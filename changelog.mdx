## Release history

1. **Unreleased**
   - **API**
     - Added `GET /api/telemetry/loading-durations` and `POST /api/telemetry/loading-durations` endpoints for client-side loading phase duration tracking. Both endpoints are unauthenticated.
     - Added optional `testRunId` field to `POST /api/agents/publish` for seeding credit estimates from measured test-run LLM costs.
     - Added `manual` as a valid `triggerType` value on `POST /api/marketplace/paste` for manually-triggered workflows.
     - Updated `GET /api/automations` response: `steps`, `creditsPerRun`, and `nextRunAt` fields are now populated with real data instead of placeholder values.
     - Added `manual` kind to the `IntrospectionTrigger` type union, mapping to the `on-demand` deployment mode.
   - **Docs**
     - Added Telemetry API reference page documenting both loading-duration endpoints with parameter specs, validation rules, and examples.
     - Updated NestJS API reference page with agent publishing, marketplace publishing, and automation listing endpoint documentation.
     - Expanded OpenAPI specification to include telemetry, agents, marketplace, and automations endpoints with schemas and examples.
   - **Fixes**
     - Corrected `APP_WEBHOOK` trigger strategy classification so webhook-piece triggers are properly recognized.
