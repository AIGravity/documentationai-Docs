## Release history

<Update label="2026-03" description="Initial platform launch" tags={["feature", "improvement", "bugfix"]}>

### New features

- Launched the Gravity platform on a shared monorepo foundation with Remix, NestJS, and FastAPI services.
- Added automated [CI/CD pipelines](/ci-cd-pipelines) for build, test, and release workflows.
- Added a [semantic versioning system](/service-versioning) for coordinated platform releases.

### Updates

- Migrated the frontend stack to Remix v2 for the initial production release.
- Upgraded styling to Tailwind v4 to align the launch baseline.
- Published the [Quickstart](/quickstart) for first-time setup and local validation.

### Bug fixes

- Fixed CI workflows that could trigger themselves during release automation.
- Fixed Docker TypeScript config resolution during image builds. See [Docker images and packaging](/docker-images-and-packaging).

</Update>
