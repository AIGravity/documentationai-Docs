## Before you start

You need **Python 3.12 or newer** and [uv](https://docs.astral.sh/uv/), which installs the CLI without fuss. A coding assistant (Claude Code, Codex or similar) does most of the writing.

## The first ten minutes

<Steps>
  <Step title="Install the CLI" icon="download" title-type="p">
    ```bash
    uv tool install gravity-cli
    ```

    The CLI keeps itself current. When a new release comes out it updates itself, rewrites the guides in your agent's folder and shows what is new.
  </Step>

  <Step title="Sign in" icon="log-in" title-type="p">
    ```bash
    gravity login
    ```

    Your browser opens on a Google sign-in. Over SSH or on a machine without a browser, `gravity login --no-browser` prints a link and a code to use on any device.
  </Step>

  <Step title="Make an agent" icon="folder-plus" title-type="p">
    ```bash
    gravity init my-agent
    cd my-agent
    ```

    This creates a working starter agent in a new folder, with the guides your coding assistant reads. Pick a different starting point with `--template minimal|structured|deepagent|chat`.
  </Step>

  <Step title="Build it with your coding assistant" icon="sparkles" title-type="p">
    Open the folder in your assistant and describe the agent you want. Tell it to read `Gravity.agent.md` first: it is the full technical reference, and `problem-to-agent.md` is the method it should follow.
  </Step>

  <Step title="Check it" icon="check-circle" title-type="p">
    ```bash
    gravity validate
    ```

    Runs the same checks Gravity runs when you publish, and lists every problem at once.
  </Step>

  <Step title="Try it" icon="play" title-type="p">
    ```bash
    gravity run --input query="hi"
    ```

    The starter agent asks one question, `query`. Each `--input` answers one question of your agent's form. This runs your agent on your machine against the real tools and models, so you see what a person would see. `gravity dev` opens a local page with the form, a live timeline and the result instead.
  </Step>

  <Step title="Publish" icon="upload" title-type="p">
    ```bash
    gravity build
    gravity push
    ```

    Packages the agent, uploads it and builds it on Gravity. `gravity push` waits until the build is ready or says what went wrong. `gravity agents` lists your agents, their versions and their review status.
  </Step>
</Steps>

<Callout kind="info">

A new version stays private until the Gravity team approves it. See [Publish and review](/guides/publish-and-review).

</Callout>

## Commands you will use next

| Command | What it does |
|---|---|
| `gravity tools` | The tools an agent can use, live from Gravity. `gravity tools slack` searches the list |
| `gravity connect gmail` | Connect your own account so local runs can use it |
| `gravity runs my-agent`, `gravity logs <run id>` | What happened when your agent ran on Gravity |
| `gravity docs` | Refresh the guides in your folder |
| `gravity update`, `gravity changelog` | Update the CLI and see what changed |

Add `-h` to any command to see its options. The [CLI reference](/reference/cli) lists them all.
