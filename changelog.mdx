## Latest updates

Track what's new and what's changed in Gravity. The most recent updates are listed first.

### Latest — Builder navigation & support improvements

**New Features**

- **"How it works" shortcut in the builder sidebar** — You can now jump straight to documentation from anywhere in the builder. The link appears in both expanded and collapsed sidebar views, so it's always one click away. See [Features](/features) for an overview of platform capabilities.

**Updates**

- **Support chat upgraded** — The live support chat now runs on a new provider with better account integration. When you're signed in, your conversations are automatically tied to your account. Signing out or switching accounts starts a fresh session, so your chat history stays private. Visit the [Help Center](/help-center) for troubleshooting guides.
- **"Back to Gravity" button on the docs page** — This link now takes you to the builder dashboard instead of the homepage, getting you back to work faster.

**Removed**

- **External "How it works" button on the Publish Agent page** — The separate external documentation button has been removed. The same content is now accessible via the new sidebar shortcut.

## How to read this changelog

Entries are organized by **New Features**, **Updates**, and **Removed** within each release. Scan top to bottom for the newest changes first.
