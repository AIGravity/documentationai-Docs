## Release history

<Update label="2026-03-01" description="Initial release" tags={["feature", "improvement"]}>

### New features

- **CI/CD pipelines** — Added automated build and deployment workflows for the monorepo. See [CI/CD Pipelines](/ci-cd-pipelines).
- **Service versioning** — Added per-service semantic versioning so services can release independently. See [Service Versioning](/service-versioning).

### Updates

- **Frontend migration** — Moved the frontend to Remix with Tailwind CSS v4 for a simpler application shell and styling workflow. See [Frontend Application Shell](/frontend-application-shell).
- **Docker packaging** — Streamlined Docker image packaging for more consistent service builds. See [Docker Images and Packaging](/docker-images-and-packaging).

### Bug fixes

- No bug fixes to report in this release.

</Update>
