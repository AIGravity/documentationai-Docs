## Overview

This changelog tracks notable platform updates. Entries are ordered newest first.

## Release history

1. **Credit Metering Observability** (PR #183)
   - **Platform**
     - Admin billing dashboard now displays all monetary values in dollar amounts instead of raw credit counts, using a fixed conversion of 1 credit = $0.01.
     - Added a 30-day daily revenue line chart, replacing the previous period comparison bar chart.
     - Added refund metrics to the billing overview: total refunded amount, refund count, and refund rate as a percentage of revenue.
     - Added revenue split by billing surface (chat vs. marketplace) in the margin section.
     - Added a week-over-week gross margin trend indicator showing the change in percentage points.
     - Added a per-1,000-runs unit economics line showing normalized revenue, LLM cost, and margin.
     - Added an over-count warning banner when the 50,000-row scan cap is hit, indicating that displayed totals are a floor.
     - Renamed the "Creator credit coverage" label to "Creator payout coverage" in the billing leakage section.
     - Added colored directional arrows (green for positive, red for negative) on period-over-period KPI deltas.
   - **API**
     - New response fields on the admin billing overview endpoint: `marginWeekPct`, `marginPrevWeekPct`, `revenueSeries` (30-day daily revenue, IST-bucketed), `revenueByKind` (chat and marketplace split), `chargedRuns`, `refundedCredits`, `refundCount`, and `refundRatePct`.
