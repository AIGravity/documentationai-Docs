## Overview

This changelog tracks notable product updates. The most recent release is listed first.

## Release history

<Update date="September 2026">

### New Features

- **Agent review pipeline** — Admins can now review agent submissions in a dedicated workspace: run submitted agents in a test environment, inspect evidence-based findings by severity, curate and edit findings before sending them to builders, and re-run quality reviews without re-executing the workflow. Builders see a clear submission lifecycle (running checks → in review → published or rejected), can resume stuck submissions, edit and resubmit rejected agents, and respond to admin feedback with thumbs up/down and notes. [Learn more →](/features)

- **Subscription plans** — Two plans are now available: Free (50 credits/month, $0) and Pro ($20/month, 2,000 credits). Subscriptions support checkout, cancellation, upgrades, downgrades, and per-cycle credit budgets. See the [API reference](/api-reference/nestjs-api) for available endpoints.

- **Creator earnings** — Builders can view lifetime and withdrawable earnings, per-agent metrics (earnings, users, runs), connect payout methods, enable auto-withdrawal with a configurable threshold, and see full payout history.

- **Referral program** — Builders can share agent invite links and personal referral codes. Referred users boost the creator's earnings share from 20% to 30%. Referrers earn a percentage of a referred builder's creator earnings for the first year, settled monthly.

- **Runtime version detection** — Gravity now detects the workflow engine's installed version at runtime instead of requiring synchronized releases, reducing breakage when the underlying engine is upgraded independently.

### Updates

- **Clearer workflow run explanations** — Paused runs, trigger failures, and run errors now show human-readable explanations in the UI instead of generic status messages.

- **Improved workflow reliability** — Better handling of paused runs, AI provider response changes, unavailable workflow pieces, and schedule trigger failures.

### Bug Fixes

- **Production AI service endpoint** — The production API was calling a stale, non-production AI service URL, which broke chat, guardrails, and marketplace builder tests. Production now uses its own AI service endpoint.

- **Marketplace errors in non-production** — The marketplace and workflow introspection were returning 500 errors due to a misconfigured database hostname. The deployment now supplies the correct hostname.

</Update>
