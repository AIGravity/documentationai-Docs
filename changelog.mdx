## Overview

This page tracks notable user-facing changes to the Gravity platform. Use it to see what changed in each release, what improved, and which issues were fixed.

## Release history

<Update label="2026-07-04" description="PR #177" tags={["feature", "bugfix", "improvement"]}>

<Update.Section title="New features">

- **Credit purchases now support EUR and GBP.** You can buy credits in euros (`€`) and British pounds (`£`) at checkout. These currencies were previously listed as coming soon, and package prices now convert using the live exchange rate at the time of purchase.

</Update.Section>

<Update.Section title="Bug fixes">

- **New chats now start fresh every time.** Opening the chat page, visiting a direct chat URL, or returning after login no longer continues a previous conversation by mistake.
- **New conversations appear in the sidebar immediately.** After you send the first message, the conversation shows up right away with the message text as the title, before saving finishes in the background.
- **Chat question cards now show the correct title.** The main title now displays the actual question prompt, and any helper text appears as a smaller subtitle below it.
- **Builder earnings now show real revenue values.** Builder dashboards and individual agent pages no longer display zeroed earnings when revenue exists.
- **Earnings now appear for more valid builder accounts.** Builders no longer need a specific account categorization for earnings data to display.
- **On-demand consumer runs now count toward agent run statistics.** Builder dashboard totals now include these runs in agent activity counts.
- **The builder earnings page no longer redirects valid builders unexpectedly.** Builders with untyped accounts can now open earnings from the dashboard without being sent away.

</Update.Section>

<Update.Section title="Improvements">

- **Connected apps in Builder Settings now use the current connection flow.** The tab now shows real connection status and lets you disconnect or reconnect accounts directly, matching the behavior on the My Apps page.

</Update.Section>


</Update>
