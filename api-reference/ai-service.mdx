## Overview

Use the AI interaction layer to manage chat sessions, evaluate agent workflows, run guardrail checks, generate verification data, and index agent content. The service listens on port `8001` when run directly and does not use a global URL prefix.

## Service configuration

The FastAPI application is named **Gravity Interaction Layer**. Its routers expose credits, verification, and agent review capabilities through the `/credits`, `/verification`, and `/agent-review` prefixes.

The service adds Sentry context for each request, including the HTTP method, request path, and request ID. For chat and internal guardrail requests, the middleware also extracts `user_id` values from request bodies when available.

Routes do not use FastAPI authentication or API-key dependencies. Routes under `/internal/` are intended for trusted internal services and network-level access controls.

<Callout kind="alert">

Protect internal routes at the network or gateway layer. The application does not enforce authentication for `/internal/` routes.

</Callout>

Invalid request data returns FastAPI's standard `422 Unprocessable Entity` response.
