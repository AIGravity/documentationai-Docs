## Overview

The FastAPI AI service runs on port 8000 and exposes four documented endpoints: `GET /health`, `POST /chat`, `POST /admin/pricing`, and `POST /internal/guardrail/check`.

<Callout kind="info">

Implementation details on this page were derived from code analysis of `apps/ai-service/main.py`, `src/models/models.py`, and `src/models/admin_pricing.py`. Direct repository file reads for code files were not available through the docs repository tool for this task.

</Callout>

#### Error responses

- **`503 Service Unavailable`**: Returned when no LLM API key is configured. The response body is `{"detail":"Chat service unavailable - no LLM API key configured"}`.
- **`422 Unprocessable Entity`**: Returned when the request body fails validation, including missing required fields, an invalid UUID, or a message longer than 4000 characters.

<ParamField body="method" param-type="string" required="true" show-location="false">

`POST`

</ParamField>

<ParamField body="path" param-type="string" required="true" show-location="false">

`/admin/pricing`

</ParamField>

<ParamField header="x-admin-token" param-type="string" required="true">

Admin authentication token matching the `ADMIN_API_TOKEN` environment variable.

</ParamField>

<Callout kind="alert">

This endpoint requires the `x-admin-token` header. If the token is missing or does not match the configured `ADMIN_API_TOKEN`, the server returns `403 Forbidden`.

</Callout>

</ParamField>

<ParamField body="output_cost_per_million" param-type="number or null" required="false" show-location="false">

## Implementation notes

The FastAPI file defines the application with `app = FastAPI()` and registers the documented health, chat, pricing, and guardrail handlers directly. The chat, pricing, and guardrail request and response structures are defined across the service models and pricing modules.

The service also exposes internal routes for requested agents, embeddings, agent indexing, credits and usage tracking, agent verification with SSE streaming, and agent review. These routes are not documented here because they are internal service-to-service endpoints.

## Likely error responses

The service can return the following responses based on the requested path, method, authentication state, and request payload:

- **`404 Not Found`**: Returned for undefined paths or unmatched method and path combinations.
- **`403 Forbidden`**: Returned by `/admin/pricing` when the admin token is missing or invalid.
- **`422 Unprocessable Entity`**: Returned by `POST` endpoints when the request body fails validation.
- **`500 Internal Server Error`**: Possible for unexpected runtime failures.
- **`503 Service Unavailable`**: Returned by `/chat` when no LLM API key is configured.
