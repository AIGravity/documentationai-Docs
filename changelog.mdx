## Overview

This changelog lists verified, reader-facing changes for Gravity. The latest entry reflects the current scaffolded product surface across the web app, backend API, AI service, and health checks.

<Callout kind="info">

Gravity is still an early scaffold. The current release establishes service foundations and local verification paths, but it is not yet a feature-complete workflow application.

</Callout>

## Release history

<Update label="Latest" description="Initial product scaffold" tags={["feature"]}>

### New features

- **Initial web app** — Added the frontend application shell with starter routes, global styling, a visible welcome screen, and baseline error handling. See [Frontend Application Shell](/frontend-application-shell).
- **Backend API** — Added the backend API foundation as the service boundary for future application workflows. See [Architecture Overview](/architecture-overview).
- **AI service** — Added the AI service foundation for future AI-related capabilities. See [Architecture Overview](/architecture-overview).
- **Service health checks** — Added health endpoints for the backend API and AI service so you can verify that each service is running locally. See [Health Checks](/health-checks).

### Current product scope

- Gravity currently provides a runnable scaffold, not a complete workflow app. Use the [Quickstart](/quickstart) to start the services and confirm the implemented surface area.

</Update>

## How to read this changelog

Scan newest entries first. Each entry lists user-facing changes only and keeps implementation details out of the release notes.
