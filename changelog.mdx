## Overview

This changelog tracks user-facing changes, bug fixes, and platform improvements. Entries are organized by release, with Platform changes and Fixes under each entry.

## Release history

<Update label="2026-07-01" description="Chat UI fixes and user experience improvements">

### Platform changes

- Bounties page now requires authentication — unauthenticated users see a sign-in prompt.
- Requested Agents page now requires authentication — unauthenticated users see a sign-in prompt.
- Bounties page gains a sort dropdown with `Newest`, `Oldest`, `Highest`, and `Lowest first`, with preference persisted across sessions.
- Bounties and Requested Agents pages now use paginated `Load more` instead of showing all items at once, with 10 per page for bounties and 14 for requested agents.
- Requested Agents cards include a save button; saved agents appear in a dedicated `Saved` section and persist across sessions.
- Settings default route changed from Profile to Credits. The sidebar gear icon and `/settings` now navigate to `/settings/credits`, and Credits is the first tab in the settings sidebar.
- Currency picker moved from the Profile settings tab to the Credits settings tab, available to all users.
- Credit balance row removed from Profile settings — credit info is consolidated on the Credits tab.
- Agent publishing now requires at least one category before proceeding, with an inline error if none is selected.
- Builder dashboard earnings card is now clickable, navigating to the earnings page.
- Builder dashboard hides the `Published` tab for new builders with pending submissions but no published agents.
- Onboarding combobox dropdowns show the full option list on focus instead of remaining empty until typing.
- Screenshot annotator redesigned as a floating modal with icon-based toolbar. New tools: Arrow and Text. Action button label changed from `Save` to `Done`.

### Fixes

- Session expiry now triggers a clean sign-out with redirect to `/dashboard` instead of leaving you on a broken page.
- Protected pages proactively validate session on mount, catching revoked sessions immediately.
- Credit balance animation no longer flashes the full number before animating from zero on page load.
- Add Credits amount field rejects non-numeric input and no longer shows a duplicate currency symbol in the placeholder.
- Dashboard prompt bar hides after bounty posting instead of showing a disabled, purposeless input.
- Password show/hide toggle button is excluded from keyboard tab order and now includes proper aria labels for screen readers.


</Update>
