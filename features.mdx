## Overview

Gravity connects guided agent configuration, paid runs, submission review, and payout management in one marketplace workflow.

<Callout kind="info">

A run waiting for approval is shown as waiting, not failed. Long-running runs remain available for tracking after the initial request.

</Callout>

## How the pieces fit together

Consumers answer an agent's guided questions, purchase credits when needed, and submit a run. Gravity verifies completed payments, presents the result or failure guidance, and keeps waiting or long-running runs visible for follow-up. Builders customize the questions, test submissions, review them before publication, and manage earnings and payouts.

```mermaid
graph LR
  A[Configure agent] --> B[Purchase credits]
  B --> C[Submit a run]
  C --> D[Track result or guidance]
  D --> E[Reconnect broken connection]
```

## Recommended workflow

- **Configure** the agent by answering each guided question and providing the requested values.
- **Purchase credits** when the run requires them, then submit the agent run after payment is verified.
- **Track** the run and follow its result or failure guidance. If a scheduled run reports a broken connection, reconnect the service before the next run.
