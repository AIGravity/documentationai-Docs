## Overview

Gravity now has a verified initial release entry based on shipped product behavior. Read newest entries first, then follow the linked docs for setup, service details, packaging, and release automation.

<Callout kind="info">

This changelog includes user-facing product changes only. Internal repository paths, implementation details, and non-functional comment-only changes are intentionally excluded.

</Callout>

## Release history

<Update label="Initial release" description="v0.1.0" tags={["feature", "improvement"]}>

### New features

- **Web application shell** — Shipped the initial Gravity web shell with a starter landing page, light and dark logo support, baseline routing, shared styling, and route-level error handling. Start with [Getting Started](/quickstart), then review the [Frontend Application Shell](/frontend-application-shell).
- **API health endpoint** — Shipped the NestJS API service with a health check at `GET /api/health` so operators can confirm the API is running. See the [NestJS API](/api-reference/nestjs-api).
- **AI service health endpoint** — Shipped the AI service with a health check at `GET /health` so operators can confirm the AI service is running. See the [AI Service](/api-reference/ai-service).
- **Published container artifacts** — Published container images for the web app, API service, and AI service through the release pipeline. See [Docker Images and Packaging](/docker-images-and-packaging).

### Updates

- **Service versioning and release automation** — Added independent service versioning, release tags, generated releases, and branch-aware image tags for main and development builds. See [Service Versioning](/service-versioning) and [CI/CD Pipelines](/ci-cd-pipelines).

### Bug fixes

- No user-facing bug fixes shipped in this release.

</Update>
