## Overview

The NestJS API service listens on port `3001` and enables CORS for `http://localhost:3000`. Swagger UI is available at `GET /api/docs`.

A global validation pipe transforms request values, removes unknown properties, and rejects non-whitelisted properties. Most routes require a Supabase JWT through `SupabaseAuthGuard`. Routes marked public bypass JWT authentication, including webhooks, public marketplace workflow details, leaderboard endpoints, and health checks. Administrative routes require both an authenticated user and admin authorization.

Use a bearer token in the `Authorization` header for authenticated requests.

## Error responses

All normalized errors use the following shape:

<Callout kind="info">

The `requestId` field is included when the request provides an `x-request-id` value.

</Callout>

```json
{
  "statusCode": 400,
  "error": "BadRequestException",
  "message": "Request validation failed",
  "path": "/api/resource",
  "timestamp": "2026-09-28T12:00:00.000Z",
  "requestId": "req_7f2a9c"
}
```

| Code | Meaning |
|---|---|
| 400 | Validation failure, malformed input, or missing required values |
| 401 | Missing or invalid Supabase JWT, webhook signature, or provider credentials |
| 402 | Payment or credit requirement not satisfied |
| 403 | Admin, user-type, or ownership restriction |
| 404 | Missing resource, disabled feature, or subscription not found |
| 409 | Conflict such as duplicate signup or duplicate state |
| 422 | Semantically unrunnable workflow, provider or trigger failure, or domain validation failure |
| 500 | Unexpected server error sanitized to a generic message |
| 502 | AI-service or provider failure |
| 503 | AI service or provider unavailable |
