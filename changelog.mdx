## Overview

Gravity launches with independent service versioning, per-service release pipelines, and a web foundation that matches the current frontend and packaging stack.

## Release history

<Update label="Initial release" description="v0.1.0" tags={["feature", "bugfix"]}>

### New

- Added per-service semantic versioning for the web, API, and AI service, with each service tracking its own `VERSION` file and release flow. See [Service Versioning](/service-versioning).
- Added dedicated CI/CD pipelines for each service that build artifacts, publish Docker images to GitHub Container Registry, and create GitHub Releases on `main`. See [CI/CD Pipelines](/ci-cd-pipelines).

### Updates

- Standardized the web frontend on Remix v2, including the current root layout, file-based routes, and Vite-based build flow. See [Frontend Application Shell](/frontend-application-shell).
- Upgraded the web styling stack to Tailwind CSS v4 with the Vite plugin and CSS-first configuration model. See [Frontend Application Shell](/frontend-application-shell).

### Fixes

- Fixed the web Docker build by copying `tsconfig.base.json` into the Docker context so the TypeScript build resolves the shared monorepo base config correctly. See [Docker Images and Packaging](/docker-images-and-packaging).

</Update>

## How to read this changelog

Read from top to bottom for the latest verified release notes. Each entry groups changes under New, Updates, and Fixes so you can scan by impact.
