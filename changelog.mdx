Stay up to date with the latest features, improvements, and fixes shipped to Gravity.

## September 2024

### New Features

- **Agent quality review pipeline** — Submitted agents now receive an automated workflow-quality review covering data flow, control flow, configuration, reliability, grounding, and output. Builders get specific, actionable feedback instead of a simple accept/reject decision. See [Features](/features).
- **Admin test runs from the review queue** — Reviewers can execute a submitted agent end-to-end before approving or rejecting it, using a dedicated review workspace with pre-collected builder answers.
- **Editable builder reports** — Admins can curate which findings to send, adjust severity, edit text inline, and reopen previously sent reports so builders receive human-reviewed feedback with a clear path to resubmit.
- **Builder feedback on review findings** — Builders can mark individual findings as fair or incorrect and add explanatory notes visible to admins, creating a two-way feedback loop.
- **Feedback badges on dashboards** — Builder and admin dashboards now show unread feedback and reply badges so new review activity is easier to discover.
- **Evidence-aware review scores** — Reviews separate evidence into static workflow, runtime execution, and output categories, so reviewers can tell whether a clean result reflects genuine quality or simply an unevaluated axis.
- **Re-run reviews** — Admins can request a fresh review using stored workflow, run output, and builder brief without re-executing the agent.

### Updates

- **Version-aware integration compatibility** — Gravity now detects the connected integration engine version and adjusts compatibility behavior automatically, so scheduled agents are less likely to break during upgrades. See [Integrations](/integrations).
- **Cost-aware AI model selection** — Model selection now checks live pricing and substitutes lower-cost alternatives when a model exceeds a price ceiling, reducing the risk of unexpectedly expensive agent runs.
- **Long-running automations** — Runs that exceed the gateway timeout now return a pending status instead of failing, with background polling that continues without duplicate execution or billing.
- **Scheduled trigger diagnostics** — Trigger-enable failures now surface the actual reason, including the problematic app or trigger version, instead of appearing to succeed and then silently never running.

### Bug Fixes

- **Actionable marketplace failure messages** — Agent failures now show a clear verdict, the underlying provider error, a suggested fix, and a collapsible technical response, replacing generic error pages. See [Help Center](/help-center).
- **Queued and paused runs** — Slow-starting, delayed, and approval-based automations no longer display misleading failure messages. Paused runs now correctly distinguish between approval, delay, and in-progress AI work.
- **Email provisioning fix** — Accounts whose email differs only by capitalization or trailing whitespace no longer get stuck during provisioning.
- **File proxy security** — File URL rewriting is now restricted to Gravity's own integration host, preventing third-party URLs from being incorrectly proxied.
