## Latest release

This release makes each Gravity service runnable, packageable, and releasable from the monorepo while keeping service releases independent.

<Update label="Latest" description="Service foundations and release automation" tags={["feature", "improvement"]}>

### New features

- **Web shell** — The web app now ships with a Remix and Tailwind shell for the application layout, route rendering, and global styling. See [Frontend Application Shell](/frontend-application-shell).
- **Service health endpoints** — The NestJS API and FastAPI AI service now expose runnable health endpoints so deployments can confirm service readiness. See [Health Checks](/health-checks), [API Service Foundation](/api-service-foundation), and [AI Service Foundation](/ai-service-foundation).
- **Automated releases** — The web, API, and AI services now publish containers and GitHub releases through service-specific release flows. See [CI/CD Pipelines](/ci-cd-pipelines).

### Updates

- **Independent service versions** — Each service now has its own semantic version so web, API, and AI service releases can move at their own pace. See [Service Versioning](/service-versioning).
- **Simplified web packaging** — The web service container packaging now uses a smaller runtime image focused on the built application and production dependencies. See [Docker Images and Packaging](/docker-images-and-packaging).

### Bug fixes

- No end-user-facing bug fixes are included in this release.

</Update>
