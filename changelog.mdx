## Overview

This changelog covers notable product updates, improvements, and bug fixes shipped to the Gravity platform. Newest entries appear first.

## Release history

<Update label="Unreleased" description="Current changes" tags={["feature", "improvement", "bugfix"]}>

### New Features

- **Bounty creation wizard** — Bounties now follow a guided three-step flow: describe your task, pick preferred tools from a searchable grid, and preview what builders will see before posting. Bounty descriptions can be auto-drafted from your chat, and bounties require payment to go live.
- **Bounty submission review** — Bounty owners get a dedicated Updates feed in the sidebar with a full submission review interface. Shortlist, reject, or try submissions before accepting the winning build, and submissions remain hidden until the bounty's reveal date.
- **My Agents with Running and One-Time tabs** — The agents page now separates scheduled agents from one-time marketplace runs. Tab state persists in the URL so navigating back restores your view.
- **Live tool status and reconnect** — Agent detail pages show real-time connection status for each tool. Disconnected tools have a Reconnect button, and disconnecting an app connection now auto-pauses any agents that depend on it.
- **Agent edit and delete** — Builders can edit a published agent's configuration or delete it from the agent details page.
- **Durable runs** — Agent runs now survive tab closes. Reopening a chat reattaches to the in-progress run instead of starting over or hanging indefinitely.
- **Resumable publish pipeline** — The agent publishing flow saves progress server-side. Leave mid-verification and resume from the dashboard, with a status bar showing the current pipeline stage.
- **Builder question confirmations** — Chat questions now require explicit confirmation before advancing, preventing accidental skips. Builders can define fixed answer options that render as selectable chips.
- **Public builder leaderboard** — A new leaderboard page ranks builders by total agent runs, agents published, and users reached.
- **Searchable option lists** — When a question offers options, you can type to filter them. Multi-value inputs show entries as removable pill tokens.

### Updates

- **Chat timeout extended** — Agent responses now wait up to 130 seconds instead of 30, accommodating longer-running tasks.
- **Run again for on-demand agents** — On-demand agents on the detail page have a Run Again button that returns you to the originating chat.
- **USD-only currency** — Pricing and earnings are standardized to USD across the platform.

### Bug Fixes

- **Sessions merging** — New chat sessions no longer accidentally append messages to a previous session.
- **Sign-in false failure** — Fixed an intermittent error that blocked sign-in even when the verification code was valid.
- **Publish flow freeze** — Resolved a freeze that could occur when re-entering the publish flow in edit mode.
- **Storage quota handling** — Sign-in no longer fails when browser storage is near capacity.


</Update>
