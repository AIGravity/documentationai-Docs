## Changelog

Notable product changes, newest first.

<Update label="2026-07-18" description="July 2026">

### Updates

- **Publish Gate requirement temporarily suspended** — Agent publishing, bounty submissions, and the agent editing flow are no longer blocked when the Publish Gate piece is missing from a workflow. This is a temporary measure while an upstream dependency issue is resolved. All other workflow validations, including blocked AI provider checks, invalid JSON detection, duplicate submission prevention, and file type enforcement, remain active. See [Features](/features) for details on supported workflows.

### Bug fixes

- **Back to edit no longer forces re-upload** — Clicking **Back to edit** on a published agent's details page now opens the customization flow directly instead of redirecting to the upload screen when the Publish Gate piece is absent.


</Update>

## How to read this changelog

Scan from top to bottom — newest entries are first. Updates are grouped by new features, then updates, then bug fixes.
