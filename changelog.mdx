## Release history

1. <Update label="July 2026" description="Latest">

### Platform

- Bounty detail pages now show a single streamlined overview instead of separate `Overview` and `User answers` tabs.
- You now see the bounty description and the original user prompt in one view when the prompt is available.
- Each bounty card now shows a payout formula based on difficulty and your Agent Quality Score:
  - **Easy** — ×20
  - **Medium** — ×25
  - **Hard** — ×30
- Submission count now appears at the top of the bounty card header, so you can spot activity faster.
- Structured specification details such as trigger timing, output destination, and rules no longer appear to builders. Administrators still have access to those details.

### Fixes

- Leaderboard closing date extended from July 30 to July 31, 2026.


</Update>
