## Release history

<Update label="2026-03" description="March 2026 release" tags={["feature", "improvement"]}>

### New features

- **CI/CD pipelines for all three services** — Added automated pipelines for the web, API, and AI services. Every push to `main` now builds each service, applies versioning rules, publishes Docker images to GHCR, and creates a GitHub Release. See [CI/CD Pipelines](/ci-cd-pipelines) and [Docker Images and Packaging](/docker-images-and-packaging).
- **Per-service semantic versioning** — The web, API, and AI services now track independent versions, each starting at `0.1.0`. Versions auto-bump from commit message conventions, and published images are tagged as `latest`, `dev-latest`, and the commit SHA. See [Service Versioning](/service-versioning) and [Docker Images and Packaging](/docker-images-and-packaging).

### Updates

- **Version bump script** — Added `pnpm version:<service>:<type>` wrappers for controlled `major`, `minor`, and `patch` bumps per service when you need an explicit release increment. See [Repository Automation Scripts](/repository-automation-scripts) and [Service Versioning](/service-versioning).

### Bug fixes

- No bug fixes to report in this release.

</Update>
