## Overview

Track notable product changes shipped in each release. Entries are organized by new features, updates, and bug fixes.

<Update date="2026-07-01">

### New features

- **Screenshot annotation tools** — Arrow and text tools added to the screenshot annotator. Draw arrows to point things out, or click to add text labels directly on screenshots.
- **Save requested agents** — Heart any requested agent to bookmark it for later. Saved agents persist across sessions and appear in a dedicated row.
- **Bounty sorting** — Sort available bounties by newest, oldest, highest, or lowest value. Your preference is remembered between visits.
- **Currency picker on Credits page** — Set your default currency directly from the Credits settings page.
- **Clickable earnings card** — Builders can click the Total earnings stat on the dashboard to jump straight to the earnings page.

### Updates

- **Screenshot annotator redesign** — The annotator now opens as a focused floating dialog with a semi-transparent overlay, an icon-based toolbar, and contextual hints that adapt to the active tool.
- **Settings reorganization** — Credits is now the default settings page and appears first in the sidebar. Credit balance and top-up controls have moved from Profile to Credits.
- **Bounties load-more** — Replaced the all-or-nothing "Show all" toggle with progressive "Load more" pagination for smoother browsing.
- **Category required for publishing** — Builders must select at least one category before publishing an agent.
- **Published agents tab** — Hidden when empty, reducing unnecessary empty states for new builders.
- **Bounties require sign-in** — The bounties page is now accessible only to signed-in builders.

### Bug fixes

- **Credit balance animation** — Fixed the count-up animation flashing the full balance before resetting to zero.
- **Duplicate currency symbol** — Fixed the Add Credits input showing a doubled dollar sign.
- **Session expiry** — Expired sessions now redirect to the dashboard instead of leaving a broken half-authenticated page.
- **Bounty posted prompt bar** — The input bar is now fully hidden after posting a bounty instead of showing a disabled state.
- **Onboarding dropdown** — Combobox fields now show all available options on focus instead of requiring typing first.
- **Password field accessibility** — The show/hide password toggle is no longer in tab order and has a proper screen-reader label.
- **Text annotation Esc key** — Pressing Esc while typing a text label now only cancels that label, not the entire annotation.


</Update>

## How to read this changelog

Entries are listed newest first. Each entry is organized into **New features**, **Updates**, and **Bug fixes** so you can quickly find what matters to you.
