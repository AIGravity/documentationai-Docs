## July 2025

<Update label="2025-07" description="AI agent copy generation update" tags={["feature", "improvement"]}>

### New features

- AI now writes your agent **title**, **description**, and **what problem does it solve** fields automatically as soon as you upload a workflow.
- Generation uses your workflow's existing name and description as source context, so the draft starts from what you already wrote.

### Updates

- A **Writing with AI…** indicator appears next to each field while generation is running.
- Auto-generation runs only on **fresh uploads**.
- When you edit a published agent, resume a draft, or return from a tool-connection redirect, existing field text stays unchanged.

<Callout kind="tip">

If you start typing before AI finishes, your text wins. The generated result never overwrites what you entered.


</Callout>

### Removed

- Removed the per-field **Improve with AI** buttons.
- Automatic generation now replaces the previous button-based workflow.

See [Features](/features) for a full overview of platform capabilities.


</Update>
