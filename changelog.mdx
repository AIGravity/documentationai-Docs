## Release history

<Update label="2026-06-28" description="Sentry Tracing Improvements" tags={["bugfix"]}>

### Bug Fixes

- **Full tracing coverage in production.** Sentry performance monitoring now captures 100% of transactions instead of the previous 10% sampling rate. This means every page load, navigation, and request is now visible in Sentry's performance dashboard — no more gaps where slow or failed requests go undetected.
- **End-to-end trace propagation.** Tracing context is now forwarded to API requests, stitching browser and server traces into a single unified waterfall in Sentry. This makes it easier to diagnose latency and errors across the full request lifecycle.


</Update>
