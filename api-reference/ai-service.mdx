## Overview

The AI service is a FastAPI application running on port 8001. It provides chat, guardrail, agent, embedding, credit, verification, and review endpoints.

The service has no global authentication middleware. Some routes enforce explicit credentials, such as the `x-admin-token` header required by `/admin/pricing`. Internal routes under `/internal/*` rely on network-level protection.

Pydantic models validate request bodies. Invalid bodies return `422 Unprocessable Entity`.

## Error responses

| Code | Meaning |
|---|---|
| 422 | Pydantic validation failure or invalid request body |
| 500 | Unhandled processing failure |
| 502 | AI or provider failure, such as embedding or generation failure |
| 503 | Service or provider unavailable, such as missing API keys |

<ParamField body="user_id" param-type="UUID" required="true">

</ParamField>

<ParamField body="session_id" param-type="UUID" required="true">

</ParamField>

<ParamField body="message" param-type="string" required="true">

User message. The value must contain between 0 and 4000 characters.

</ParamField>

<ParamField body="selected_tools" param-type="string[]" required="true">

Tools selected for the interaction.

</ParamField>

<ParamField body="submit_tools" param-type="boolean" required="true">

Whether the selected tools should be submitted for execution.

</ParamField>

<ParamField body="agent_id" param-type="UUID" required="false">

Agent to use for the interaction. If omitted, the service determines the applicable agent.

</ParamField>

<ResponseField name="session_id" field-type="UUID" required="true">

Session associated with the interaction.

</ResponseField>

<ResponseField name="reply" field-type="string" required="true">

Assistant response text.

</ResponseField>

<ResponseField name="question" field-type="string" required="false">

Follow-up question generated for the interaction, when applicable.

</ResponseField>

<ResponseField name="options" field-type="array" required="false">

Options associated with a follow-up question or interaction decision.

</ResponseField>

<ResponseField name="mode" field-type="string" required="true">

Interaction mode selected by the service.

</ResponseField>

<ResponseField name="ready_to_query" field-type="boolean" required="true">

</ResponseField>

<ResponseField name="suggested_tools" field-type="array" required="false">

Tools suggested for the interaction.

</ResponseField>

<ResponseField name="execution_id" field-type="string" required="true">

</ResponseField>

The service creates an execution row for each request and finalizes it as completed or failed.
