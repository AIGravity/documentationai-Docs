## Overview

This changelog tracks notable product updates and changes shipped to Gravity.

## Release history

<Update date="2026-07-16">

### New Features

- **AI-powered category suggestions** — When you upload a workflow, suggested marketplace categories are auto-filled for you to confirm or adjust. See [Features](/features).
- **Leaderboard redesign** — Rankings now track individual workflows with phase-aware views (locked, live, ended) and frozen final results. Prize tiers and an incentives section have been updated.
- **Bounty difficulty levels** — Bounties are now tagged Easy, Medium, or Difficult. Filter by difficulty and spot them at a glance with colour-coded indicators.
- **Expanded bounty marketplace** — 34 new automation tasks have been added across popular tools.

### Updates

- **Sharper AI-generated text** — Agent names and descriptions are now plainer, more outcome-focused, and free of stray dashes. See [Features](/features).
- **Builder-aware sign-in** — Sign-in prompts on builder surfaces open directly to the Builder tab, and builders land on the builder dashboard after logout.
- **Sidebar visible without sign-in** — Builder-facing pages now show the sidebar to unauthenticated visitors instead of a blank screen.
- **Shuffled bounty grid** — Bounties are randomized on each page load for fairer visibility.
- **Corrected integration labels** — Tool display names now use proper brand casing (e.g., Fireflies.ai, TickTick, PostHog). See [Integrations](/integrations).
- **AI-assist reminder** — Fields filled by "Improve with AI" now display a note prompting you to verify the content.
- **Finer quality scores** — Agent quality scores now show two decimal places.

### Bug Fixes

- **Cleaner rejection messages** — Raw quality scores are no longer exposed in builder-facing rejection notices, replaced with a clear, generic explanation.
- **Removed non-functional button** — A dead "More actions" button in the admin review panel has been removed.





</Update>
