## Overview

This changelog tracks notable product changes to the Gravity platform — new features, updates, and bug fixes.

<Update label="March 7, 2026" description="Initial release">

### New features

- **Independent service versioning** — Each service (web, API, and AI service) now tracks its own semantic version independently. Versions auto-increment based on commit message conventions, so you always know which version of each service is deployed. See [Service Versioning](/service-versioning).
- **Automated CI/CD pipelines** — All three services now have end-to-end CI/CD pipelines that handle building, versioning, Docker image publishing to GitHub Container Registry, and GitHub release creation automatically on every push to `main`. See [CI/CD Pipelines](/ci-cd-pipelines).

### Updates

- **Frontend stack** — The web application is built on Remix v2 and Tailwind CSS v4, providing a modern frontend foundation with server-side rendering, file-based routing, and the latest styling capabilities. See [Frontend Application Shell](/frontend-application-shell).

</Update>
