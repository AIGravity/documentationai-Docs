## Release history

<Update label="2026-06-28" description="PR #160 — Binding Dynamic Dropdown Consolidation" tags={["breaking", "feature", "improvement"]}>

### Breaking changes

- **Endpoint URL changes**
  - `POST /api/n8n-workflow/builder-fields` moved to `POST /api/marketplace/builder-fields`.
  - Composio auth endpoints moved from ` /api/n8n-workflow/auth/*` to ` /api/connections/auth/*`.

<Callout kind="alert">

Update any clients, internal tooling, or published integrations that still call the old endpoint paths. Requests to the previous routes will no longer match the current API surface.


</Callout>

### New features

- **Full consumer input support on the agent publish path**
  - Dynamic cascade fields are now handled on publish, expanding support beyond `dynamic-dropdown` and `dynamic-multi-dropdown`.
  - Refreshers, including dependent dropdown chains, now propagate through the agent publish flow.
  - Node binding targets now persist and apply at run time, so one consumer answer can fan out to multiple workflow parameters.

- **Array field type support**
  - AP `ARRAY` properties, including multi-recipient email fields, are now supported as consumer inputs.
  - Scalar string values now split automatically on commas or newlines before being mapped into array inputs.

- **Deployment mode and trigger metadata on agent publish**
  - Scheduled agents now render the correct consumer UI card instead of defaulting to the on-demand experience.

- **Credit cost auto-estimation**
  - Published agents now show an estimated credit cost per run based on AI and agent node count.

- **Clear all pending apps endpoint**
  - `DELETE /api/apps/pending/all` now clears the entire pending-apps wishlist in a single request.

### Improvements

- **Trigger-level dropdown options**
  - Trigger dropdowns now pass trigger context instead of always using action context.
  - Piece versions now read from the flow node, which prevents stale frontend versions from causing validation errors.

- **Typesense search indexing**
  - Agent publish now indexes curated metadata, including name, summary, problem solved, use cases, workflow steps, and categories, instead of raw export names.

### Removed

- **Inngest decommissioned**
  - Removed all Inngest environment variables: `INNGEST_DEV`, `INNGEST_EVENT_KEY`, `INNGEST_SIGNING_KEY`, and `INNGEST_ENV`.
  - Removed the `/api/inngest` handler and all durable workflow functions.

- **`AP_USER_PASSWORD_SECRET`**
  - Removed `AP_USER_PASSWORD_SECRET`.
  - Direct JWT minting through `AP_JWT_SECRET` now replaces the previous secret-based flow.


</Update>
