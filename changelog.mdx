<Update label="September 2026" description="New features" type="new">

### Agent review pipeline

- Added quality review with evidence-axis scoring across static, runtime, and output dimensions.
- Added admin re-review support.
- Added builder feedback on individual findings.
- Added plain-English rendering for persisted run output.

### Billing and monetization

- Added subscription plans and credit entitlements.
- Added checkout and cancellation flows.
- Added referral earnings, creator earnings balances, and payouts through Razorpay, Stripe, and PayPal.

### Public leaderboards

- Added builder and workflow rankings.

### Bounties

- Added bounty creation and builder submissions.
- Added automated payouts to winning builders.

### Candidate assignments

- Added bounty pools and task selection.
- Added scored submissions.

</Update>

<Update label="September 2026" description="Changed behavior" type="change">

- Paused runs now use typed pause reasons: approval, delay, agent, or unknown. Runs no longer treat every pause as an approval wait.
- ActivePieces compatibility shims are now version-gated using the instance's reported version.
- AI provider options in cloud-authored workflows are normalized automatically to the expected format.
- Action steps that cannot run on the current ActivePieces version are pinned or rejected early with actionable errors.
- Empty ActivePieces property-options responses now produce readable errors instead of silent JSON parse failures.
- Run failure diagnostics now preserve and classify error messages for memory limits, log size, quota exceeded, and timeout failures.

</Update>

<Update label="September 2026" description="Removed" type="remove">

- Removed legacy workflow execution endpoints.

</Update>
