## Release history

<Update label="March 2026" description="Platform and documentation updates" tags={["feature", "improvement", "bugfix"]}>

### New features

- Added [CI/CD pipelines](/ci-cd-pipelines) so teams can build, test, and ship changes through a documented delivery flow.
- Added [automated semantic versioning](/service-versioning) so service releases follow a predictable versioning process.
- Added a [manual version-bump script](/repository-automation-scripts) so maintainers can force controlled release increments when automation is not the right fit.

### Updates

- Migrated the frontend to Remix v2 and Tailwind v4 in the [Frontend Application Shell](/frontend-application-shell) docs so the web app matches the current runtime and styling stack.

### Fixes

- Fixed the Docker web image build flow in [Docker Images and Packaging](/docker-images-and-packaging) so container builds complete without the previous packaging failure.

</Update>
