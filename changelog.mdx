## Overview

This changelog tracks notable product changes shipped to Gravity. Each entry lists new features, updates to existing capabilities, and bug fixes in reverse-chronological order.

## Release history

<Update releaseDate="2026-09-10" title="September 2026">

### New Features

- **Agent Review Pipeline** — Admins can now run submitted agents, inspect human-readable outputs, review workflow quality, judge AI responses, and send structured feedback to builders. Builder answers are preserved across failed runs for easier debugging. Learn more in the [Features](/features) overview.
- **Subscriptions & Billing** — Introduced subscription quotas, Stripe checkout, creator earnings and payouts, referral earnings, and a billing dashboard. See [Features](/features) for details.
- **Runtime Safety Checkpoints** — Agents can now allow, ask for confirmation, or block before executing external actions. Fail-closed behavior applies when the safety checker is unavailable. Learn more in [Features](/features).
- **Chat Session Preservation** — Consumer chat context is now carried into cloned agent copies so runtime safety checks respect the user's original intent. See [Features](/features).
- **Activepieces Version Compatibility** — Gravity now detects the running Activepieces version and adjusts compatibility behavior accordingly, preventing breakage during AP upgrades. See [Integrations](/integrations).

### Updates

- Consumer experience improved with richer result rendering, long-run polling, dependent dropdowns, chat-bar question flows, and better builder question handling.
- Email lookups now normalize mixed-case and whitespace-padded addresses for more reliable account provisioning.
- File proxying restricted to the correct Activepieces host to prevent unsafe URL rewriting.
- Notification email delivery enabled across all deployment environments.

### Bug Fixes

- Restored production chat, guardrails, and marketplace test-builder calls by correcting the production AI service endpoint.
- Paused runs now correctly distinguish between approval, delay, and run-agent pauses, showing meaningful status messages instead of generic errors.
- Approval-paused agent runs now stay alive for up to two hours, display "Waiting for approval," and preserve their reattach handle.
- Action steps incompatible with the current Activepieces version are now pinned or rejected with a readable error instead of failing silently or timing out.
- AI provider configuration from Activepieces Cloud is now correctly normalized during publishing and cloning.
- Empty options responses from Activepieces no longer cause JSON parsing failures in dynamic question pickers.
- Recurring agents waiting for approval no longer lose their active-run handle after transient polling errors.
- Workflow submissions containing stray null characters no longer fail with a misleading database error.
- Connected-app loading and Activepieces database operations restored after a tunnel hostname fix.

</Update>
