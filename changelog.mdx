## Release history

<Update label="2025-06-28" description="Binding & Dynamic Dropdown Consolidation" tags={["feature", "improvement", "bugfix"]}>

### New features

- **Bind nodes** — When customizing an agent, you can now bind a single field across multiple workflow steps. One consumer answer fills all bound nodes automatically. A badge shows how many nodes are linked.
- **New consumer input controls** — Agents now support date pickers, file uploads, and cascading dependent dropdowns when collecting inputs from users.
- **Per-field property indicators** — Each tagged field in the agent customizer now shows a badge indicating what control type the consumer will see, including dropdown, cascade, date, and file.
- **Clear all pending apps** — You can now clear your entire "to connect" wishlist in one action from the My Apps page.

### Updates

- **Real end-to-end test runs** — "Test your agent" now performs a genuine production run that executes real actions, then immediately disables the flow. Previously, test runs skipped gated action steps entirely.
- **Accurate credit cost on deploy** — Agents published via the customize flow now show an estimated credit cost per run on the deploy card, based on the agent's structure. Previously, the cost displayed as 0 until the first real metered run.
- **Improved agent discovery** — Agents published via the customize flow now appear correctly in search with their proper name and description, instead of being invisible or poorly ranked.
- **Scheduled agents via customize flow** — Scheduled and subscription-based agents can now be published via the customize flow and correctly route to the "Schedule and Execute" card for consumers.
- **Faster connected-apps loading** — The My Apps screen now fetches all connected app statuses in a single request instead of one request per app.

### Bug fixes

- **Dependent dropdowns broken on customized agents** — Agents published via the customize flow were missing dependency metadata, causing dependent dropdowns to fail at runtime. Both publish paths now use the same enrichment logic.
- **Array inputs sent as scalars** — Multi-value fields like email recipient lists are now correctly passed as arrays instead of being flattened to a single string.
- **Bound fields not deduplicated** — When the same field was tagged on multiple bound nodes, consumers were asked the same question multiple times. Bound fields are now collapsed into a single question.
- **Builder form pagination stuck** — Inline agent form cards with incompatible fields could get stuck during pagination. The one-field-at-a-time flow now paginates correctly with Back, Next, and Run controls.


</Update>
