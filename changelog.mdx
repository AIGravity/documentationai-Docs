## Overview

This changelog tracks notable product updates and improvements to the platform.

## July 2026

### New Features

- **Verification history now influences quality scores** — Agents that pass automated verification on the first attempt now receive better initial quality scores on the leaderboard, making rankings fairer for builders who get it right the first time.

### Updates

- **Full score breakdowns stored** — Agent quality scores now capture the complete per-dimension breakdown, improving score stability over time and giving admins richer diagnostic data during the review process.

### Bug Fixes

- **Cost scoring dimension fixed** — The cost dimension was previously excluded from quality scoring because credit cost was always reported as zero. It now uses the actual credit cost from the builder's test run, so agents with lower running costs are ranked more favorably. The credit estimate shown on the admin review card also displays a real value instead of always showing zero.
