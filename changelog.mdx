## Overview

## Release history

<Update label="2026-07-04" description="Marketplace billing: admin dashboard + minimum creator payout" tags={["feature", "improvement", "bugfix"]}>

### Minimum creator payout

- Creators now earn at least 1 credit on marketplace workflow runs when their calculated share would otherwise round down to zero.
- Previously, runs charging 1–4 credits resulted in zero creator earnings due to integer flooring. This fix ensures creators are compensated for every qualifying run.
- The minimum payout does not apply to runs with zero margin, where cost equals charge, or to agents configured at 100% platform share.

### Admin billing dashboard

- A new Unit Economics panel shows revenue, metered LLM cost, and gross margin percentage.
- A new Cash and Liabilities panel displays cash collected by currency, credits purchased, user float, and outstanding creator liability.
- A new User Lookup panel lets admins search by name, email, or UUID and drill into a per-user billing view with balance, spend, creator earnings, and the last 50 runs.
- Failed charges are now broken down by cause: insufficient balance versus run failure.
- A toggle to exclude test accounts from all billing metrics is now available on the dashboard.

### API changes

- Two new admin endpoints: `GET /api/admin/billing/users/search` and `GET /api/admin/billing/users/:id`.
- All four existing admin billing endpoints now accept an optional `excludeTest` query parameter to filter out test accounts.
- The billing overview response now includes unit economics fields `llmCostCredits` and `marginPct`, cash flow field `moneyIn`, and creator liability field `creatorLiability`.
- The leakage response now includes a failed charge breakdown, `insufficient` and `runFailed`, within the `failedCharges` object.

### Fixes

- Revenue reporting day boundary now anchors to IST midnight instead of UTC midnight, correcting daily and weekly revenue figures for the Indian market.


</Update>
