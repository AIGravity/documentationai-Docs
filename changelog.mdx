## Release history

### September 2026

**New features**

- **Agent review pipeline.** Admins can now review submitted agents in a dedicated workspace with automated quality findings, evidence-backed reports, and a built-in test-run panel. Admins select and edit findings to send curated feedback to builders, who can respond per-finding and resubmit. Stale reviews can be re-run with a single click. See [Features](/features) for an overview of platform capabilities.
- **Approval-paused runs now show as in progress.** Runs waiting on an approval no longer appear as failures. The UI identifies the waiting step and app, tells the user what to do, and keeps polling — no need to restart the run. Delay and AI-agent waits show their own clear status with "nothing is needed from you" copy.

**Updates**

- **Cloud-authored agents now import correctly.** Agents exported from Activepieces Cloud that used Cloud's object-style AI provider configuration now work on self-hosted deployments. The provider is automatically converted to the local format at publish and clone time.
- **Unsupported action versions are auto-pinned or rejected early.** When a workflow step uses an action version that isn't installed, the platform pins it to the newest compatible version automatically. If no compatible version exists, the builder gets a clear error naming the affected step before the test run — instead of a blank card and a silent failure later.
- **Activepieces compatibility shims.** Version-gated compatibility checks now adapt workflow imports to the installed Activepieces version, preventing older flow versions from failing during import on newer platforms.

**Bug fixes**

- **Production AI features restored.** Chat, guardrail checks, and marketplace test-builder runs were failing in production because API requests were routed to the nonproduction AI service. Production now uses the correct AI service URL.
- **Email signup no longer fails on case or whitespace.** Email lookups now normalize case and whitespace, so mixed-case or padded email addresses match existing accounts instead of stranding users in a provisioning loop.
- **File downloads restricted to your instance.** File URL proxying now only applies to URLs from the configured Activepieces host, preventing third-party or lookalike URLs from being proxied through the platform.
