## Overview

This page documents the NestJS backend service routes currently implemented in the AIGravity core repository. The service exposes a public health endpoint at `GET /health` plus a group of admin-protected billing endpoints under `/api/admin/billing/` that require authentication and admin privileges.

<Callout kind="info">

Implementation details on this page were derived from code analysis of `apps/api/src/main.ts`, `apps/api/src/app.module.ts`, and `apps/api/src/health/health.controller.ts`, rather than direct file reads through the docs repository tool.


</Callout>

<Callout kind="alert">

The repository README mentions `GET /api/health`, but the code currently implements `GET /health`. No global prefix is configured, so the `/api` path is not active.


</Callout>

## Likely error responses

The analyzed code does not define custom error handling for this route. The most likely responses are framework-level errors.

### 404 not found

A `404` response is likely when you request the wrong path or use the wrong HTTP method. For example, `GET /api/health` or `POST /health` would not match the implemented route.

### 500 internal server error

A `500` response is only likely if the NestJS framework or runtime fails while serving the request. No route-specific error branches were found in the analyzed handler.

## Notes

The NestJS bootstrap code enables CORS for origin `http://localhost:3000` and sets `credentials` to `true`. The application listens on port `3001`, so the health endpoint is available at `http://localhost:3001/health` in the current local configuration.

## Admin Billing

These endpoints expose billing, revenue, and user-level billing diagnostics for administrators.

<Callout kind="alert">

All admin billing endpoints require authentication through a Supabase session and an authenticated user with admin privileges. Requests without a valid session receive `401` responses, and authenticated non-admin users receive `403` responses.


</Callout>

### GET `/api/admin/billing/overview`

Use this endpoint to retrieve a high-level summary of billing performance, collected credits, liability, and margin.

<ParamField query="excludeTest" param-type="string" required="false">

Pass `1` or `true` to exclude test accounts from all metrics. When omitted, the response includes all accounts.


</ParamField>

### Example request

<CodeGroup tabs="cURL">

```bash
curl -i "http://localhost:3001/api/admin/billing/overview?excludeTest=true"
```

</CodeGroup>
