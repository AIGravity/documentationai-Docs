## Overview

This changelog tracks shipped platform and documentation changes that affect developers working in the Gravity repository.

## Release history

<Update label="2026-03" description="March 2026 release" tags={["feature", "improvement"]}>

### New features

- CI/CD pipelines are now live for `web`, `api`, and `ai-service`. Each pipeline builds, versions, publishes a Docker image to GitHub Container Registry, and creates a GitHub release on every push to `main`. See [CI/CD Pipelines](/ci-cd-pipelines) and [Docker Images and Packaging](/docker-images-and-packaging).
- Per-service semantic versioning is now enforced with separate `VERSION` files for `web`, `api`, and `ai-service`. CI bumps versions from commit keywords: `[major]`, `[minor]`, or `feat:`; all other changes default to a patch bump. Manual version bumps are still supported. See [Service Versioning](/service-versioning).

### Updates

- The web frontend migrated from React Router v7 to Remix v2. See [Frontend Application Shell](/frontend-application-shell).
- Tailwind CSS in the web app moved from v3 to v4. `tailwind.config.js` and `postcss.config.js` are no longer required. See [Frontend Application Shell](/frontend-application-shell).

</Update>
