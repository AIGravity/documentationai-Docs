## Overview

The FastAPI AI service powers the conversational interaction layer, agent verification, agent quality review, and internal services for the Gravity platform. It exposes health, chat, verification, review, and internal endpoints.

## Endpoint families

- **Health:** `GET /health` for service health and chat availability.
- **Chat:** `POST /chat` for conversational interaction, agent discovery, and tool selection.
- **Agent verification:** `POST /verification/*` for workflow verification gates streamed as Server-Sent Events, description, category, and field generation, URL safety verdicts, and guardrail health.
- **Agent review:** `POST /agent-review/analyze` for structural workflow-quality analysis, runtime and output analysis, requirement coverage, and evidence-axis scoring.
- **Internal APIs:** `POST /internal/*` for guardrail checks, text embeddings, Typesense agent indexing and deletion, and requested-agent management.
- **Credits and usage:** `GET /credits/executions/{id}/usage`, `GET /credits/executions/{id}/breakdown`, and `POST /credits/internal/workflow-llm-event` for chat execution usage and workflow LLM metering.
- **Admin pricing:** `POST /admin/pricing` for model pricing overrides. This endpoint requires an admin token.

<Callout kind="info">

The `/chat` endpoint returns `503` when no LLM API key is configured. Internal and admin endpoints are intended for service-to-service calls and admin operations. Verification and review endpoints are called by the API service during agent publishing.

</Callout>

## Chat endpoint

### POST /chat

Send a chat message to the AI service for intent classification, agent discovery, and response generation.

<ParamField body="user_id" param-type="UUID" required="true">

Identifier of the user making the request.

</ParamField>

<ParamField body="session_id" param-type="UUID" required="true">

Identifier of the conversation session.

</ParamField>

<ParamField body="message" param-type="string" required="true">

Message to process. The message must contain between 0 and 4000 characters.

</ParamField>

<ParamField body="selected_tools" param-type="string array" required="false">

Tools selected by the user for the interaction.

</ParamField>

<ParamField body="submit_tools" param-type="boolean" required="false">

Whether to submit the selected tools. Defaults to `false`.

</ParamField>

<ParamField body="agent_id" param-type="string" required="false">

Identifier of the agent associated with the interaction, when an agent has already been selected.

</ParamField>

<CodeGroup tabs="cURL,JSON body">

```bash

    "message": "Find an agent that can summarize our weekly support metrics",
```

## Error responses

The AI service exposes several endpoint families, so error responses depend on the route and request.

- **`400 Bad Request`**: The request contains invalid values or cannot be processed.
- **`401 Unauthorized`**: Authentication is required or the supplied credentials are invalid.
- **`403 Forbidden`**: The caller does not have permission to use the endpoint.
- **`404 Not Found`**: The requested route or resource does not exist.
- **`422 Unprocessable Entity`**: The request body fails FastAPI validation.
- **`503 Service Unavailable`**: The chat service has no configured LLM API key or a required upstream AI dependency is unavailable.
- **`500 Internal Server Error`**: The service encounters an unexpected runtime failure.
