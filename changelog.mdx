## Latest release

<Update label="2026-07-01" description="Product update" tags={["feature", "improvement", "bugfix"]}>

### **New Features**

- Publish **Manual Trigger** agents that run when someone clicks **Run**, without requiring a webhook or schedule.
- Watch loading rings and progress bars reflect real execution timing, so progress feels closer to what the agent is actually doing.
- Show a per-agent execution estimate on first run, giving users a more accurate expectation of how long that agent usually takes.
- Reorder workflow steps with drag-and-drop or keyboard arrow keys, making agent editing faster and more accessible.
- See the next scheduled run time directly on the agent detail page for scheduled agents.

### **Updates**

- Restore your active chat session after refreshing the dashboard, and keep the correct conversation selected as you move between pages.
- Show a new **Finalizing…** status while tool connections finish after the authorization popup closes.
- Replace raw connection errors with clearer messages that explain what went wrong and what to do next.
- Standardize the draft review card across agent types, with adaptive button labels and a **try with different input** option.
- Improve day-to-day usability with larger stat boxes, wrapped long chat messages, redesigned step indicators, and scrollable rejection lists.
- Rename **Intent cleared** to **Task captured** to make workflow language easier to understand.

### **Bug Fixes**

- Close the OAuth popup promptly after successful authorization instead of leaving it open.
- Prevent false failure notices after successful tool connections by confirming the connection before showing an error.
- Render setup instructions as formatted content with working links and lists instead of raw markdown or code blocks.
- Update deploy card credit estimates to reflect the actual measured cost of the builder's test run.
- Show real workflow steps and credit costs for subscription agents on the detail page instead of empty values.
- Stop the sidebar chat list from blinking or re-fading when you navigate between dashboard sections.
- Disable the input bar when a flow reaches a terminal state so users cannot type when no further input is expected.
- Remove the **Completed in Nms** header from results to reduce visual clutter.


</Update>
