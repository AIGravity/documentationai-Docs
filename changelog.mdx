## Gravity app foundation

Gravity now includes a runnable local product baseline across the web app, API service, and AI service. Start the local experience with one command after completing the setup steps in the [Quickstart](/quickstart).

### Gravity web app foundation

- Added the first runnable Gravity web app foundation so teams can open the product locally and verify the application shell.

### API health endpoint

- Added an API health endpoint for checking backend availability. See the [API reference](/api-reference/nestjs-api) and [Health checks](/health-checks) for request and response details.

### AI service health endpoint

- Added an AI service health endpoint for checking AI service availability. See the [AI service reference](/api-reference/ai-service) and [Health checks](/health-checks) for request and response details.

### One-command local development workflow

- Added a one-command local development workflow that starts the web app, API service, and AI service together after setup. Follow the [Quickstart](/quickstart) for the full local startup flow.

### Frontend baseline and browser metadata

- Updated the frontend baseline with the current Remix and Tailwind setup, browser metadata, document defaults, font loading, and system dark-mode styling. Review the [Frontend application shell](/frontend-application-shell) for the user-visible shell behavior.

</Update>
