## Overview

This page documents the NestJS backend service route currently implemented in the AIGravity core repository. The code analysis found a single public endpoint: `GET /health`.

<Callout kind="info">

Implementation details on this page were derived from code analysis of `apps/api/src/main.ts`, `apps/api/src/app.module.ts`, and `apps/api/src/health/health.controller.ts`, rather than direct file reads through the docs repository tool.


</Callout>

<Callout kind="alert">

The repository README mentions `GET /api/health`, but the code currently implements `GET /health`. No global prefix is configured, so the `/api` path is not active.


</Callout>

## Likely error responses

The analyzed code does not define custom error handling for this route. The most likely responses are framework-level errors.

### 404 not found

A `404` response is likely when you request the wrong path or use the wrong HTTP method. For example, `GET /api/health` or `POST /health` would not match the implemented route.

### 500 internal server error

A `500` response is only likely if the NestJS framework or runtime fails while serving the request. No route-specific error branches were found in the analyzed handler.

## Notes

The NestJS bootstrap code enables CORS for origin `http://localhost:3000` and sets `credentials` to `true`. The application listens on port `3001`, so the health endpoint is available at `http://localhost:3001/health` in the current local configuration.

## Marketplace and connection endpoints

<Callout kind="alert">

The following endpoints were recently introduced or relocated. If your client still uses the previous `/api/n8n-workflow/` paths, update the integration to the current routes documented here.


</Callout>

### POST `/api/marketplace/builder-fields`

Use this endpoint to fetch the builder form fields for a published agent. The handler reads from the agent's stored consumer inputs.

<ParamField body="agentId" param-type="string" required="true" show-location="false">

The ID of the published agent to fetch builder fields for.


</ParamField>

This endpoint previously lived at `POST /api/n8n-workflow/builder-fields` and now uses the marketplace route.

### GET `/api/connections/auth/connections`

Use this endpoint to list all Composio connections for the authenticated user.

This endpoint is part of the Composio auth route relocation. Composio auth endpoints previously lived under `/api/n8n-workflow/auth/*` and now live under `/api/connections/auth/*`.

### POST `/api/connections/auth/apps`

Use this endpoint to list available Composio apps that can be connected.

This endpoint moved from `POST /api/n8n-workflow/auth/apps`.

### POST `/api/connections/auth/initiate`

Use this endpoint to initiate the Composio OAuth flow for a specific app.

This endpoint moved from `POST /api/n8n-workflow/auth/initiate`.

### POST `/api/connections/auth/status`

Use this endpoint to check the status of a Composio connection.

This endpoint moved from `POST /api/n8n-workflow/auth/status`.

### POST `/api/connections/auth/disconnect`

Use this endpoint to disconnect a Composio connection.

This endpoint moved from `POST /api/n8n-workflow/auth/disconnect`.

### POST `/api/marketplace/property-options`

Use this endpoint to fetch dropdown options for a specific piece property at runtime.

<ParamField body="pieceName" param-type="string" required="true" show-location="false">

The Activepieces piece name.


</ParamField>

<ParamField body="actionName" param-type="string" required="true" show-location="false">

The action or trigger name.


</ParamField>

This endpoint now handles trigger-level dropdowns correctly by passing trigger context instead of always using action context. It also reads piece versions from the flow node, which prevents stale frontend versions from being used.
