## Latest changes

Track product changes here as they ship, with the newest updates first. Use this page to quickly scan new features, behavior changes, and fixes.

<Update label="2026-07-13" description="Bounty pay-to-post funding via Razorpay" tags={["feature", "improvement", "bugfix"]}>

### New Features

- Bounty creators must now pay the full prize amount up front via Razorpay before their bounty goes live. Bounties stay hidden from builders until payment is verified and completed.
- Free bounties (prize set to zero) continue to post instantly — no payment step required.

### Updates

- Existing bounties created before this change remain live and are unaffected by the new payment requirement.

### Bug Fixes

- Prevented duplicate bounty creation and potential double charges if a session expired mid-flow.
- Fixed the bounty confirmation card not appearing after returning from a lost session.
- Fixed retried payments incorrectly showing as failed — successful retries now display correctly.
- Fixed the Razorpay checkout modal appearing as a blank white page in dark mode.
- Fixed slow checkout modal loading by preloading the payment SDK when the bounty preview step is reached.


</Update>
