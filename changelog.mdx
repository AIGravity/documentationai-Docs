## Release history

<Update date="September 2026">

### Platform Expansion: Agent Review Pipeline, Marketplace Reliability, and Production Deployment

#### Agent Quality Review

- Added an agent quality review pipeline that evaluates submitted workflows for structural issues, dataflow problems, reliability, AI-step substance, and output quality.
- Admins can review detailed findings with severity, evidence, and suggested fixes.
- Builders receive curated feedback reports with actionable improvement guidance.
- Builders can provide thumbs-up or thumbs-down feedback on review reports.
- Quality review is advisory and separate from publish-safety verification.

#### Marketplace Workflow Reliability

- Paused approval workflows now stay alive and can be resumed instead of appearing to fail immediately.
- Paused runs carry a classification for approval, delay, agent, or unknown states.
- Resource-limit failures for memory, log size, and quota now show readable explanations instead of generic errors.
- Cloud-authored AI provider configurations are normalized automatically instead of failing with invalid option errors.
- Unsupported action versions are rejected during preparation with named-step explanations.
- Empty dynamic option responses now show readable fallback messages instead of JSON parse errors.

#### Activepieces Integration

- Compatibility now adapts to the Activepieces instance version instead of requiring a synchronized Gravity release.
- Email lookups normalize case and whitespace to match Activepieces storage.
- File proxying applies only to URLs from the configured Activepieces host.

#### Deployment

- Pushing to main now triggers production deployment to AWS ECS automatically.
- Service-specific workflows now run build checks on pull requests only.
- Production uses production-specific AI service, Supabase, Activepieces, and payment configuration.

#### Platform Infrastructure

- Added subscription plans, entitlements, grants, reservations, and renewal processing.
- Added payout infrastructure supporting Stripe Connect, RazorpayX, and PayPal.
- Added referral earnings settlement and builder earnings display.
- Added a notifications system.

</Update>

<Update date="Prior">

</Update>
