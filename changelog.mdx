## August 2026

### New Features

- **Web application launched:** The initial web interface is now live with a responsive layout, light/dark branding, and basic navigation. See the [Frontend Application Shell](/frontend-application-shell) page for details.
- **API health endpoint:** The API service now exposes a health check at `GET /health` returning status and service identity. Useful for uptime monitoring and deployment verification. See [Health Checks](/health-checks).
- **AI service health endpoint:** The AI service now exposes a health check at `GET /health` returning a status payload. See [Health Checks](/health-checks).
- **Per-service versioning:** Each service (web, API, AI) now tracks its own semantic version independently, with automated version bumps driven by commit messages and GitHub Releases generated on the main branch. See [Service Versioning](/service-versioning).

### Updates

- **Web framework migrated to Remix Vite:** The frontend build tooling moved to Remix with Vite, bringing faster builds and modern dev server support.
- **Styling upgraded to Tailwind CSS v4:** The web application now uses Tailwind CSS v4 with its Vite integration for streamlined styling.
- **Docker packaging for all services:** Each service now has a Dockerfile for containerized builds and deployments. See [Docker Images and Packaging](/docker-images-and-packaging).
- **CI/CD pipelines for all services:** Dedicated build, version, Docker publish, and release pipelines are now active for web, API, and AI services. See [CI/CD Pipelines](/ci-cd-pipelines).

### Bug Fixes

- **Fixed web Docker builds:** Resolved a missing TypeScript configuration issue that prevented the web service Docker image from building successfully.
- **Fixed production deployment secret resolution:** Corrected environment-scoped secret selection so production deployments receive the right configuration values instead of empty placeholders.
