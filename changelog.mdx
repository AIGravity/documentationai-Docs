## Overview

This changelog tracks notable product changes, organized newest first. Each entry covers new features, updates, and bug fixes.

## Release history

<Update label="2026-07-20" description="July 20, 2026" tags={["feature", "improvement", "bugfix"]}>

### New Features

- **Prize podium preview on the pre-open leaderboard** — The gold, silver, and bronze prize tiers are now visible on the leaderboard before it opens, so you can see exactly what you're competing for at a glance.

### Updates

- **Redesigned pre-open layout** — The prize podium and countdown clock now appear side-by-side on desktop, with the podium on the left and the countdown on the right. On mobile, they stack vertically.
- **More compact countdown clock** — The countdown clock is slightly smaller to fit alongside the podium in the new layout.

### Bug Fixes

- **Fixed layout centering on the pre-open leaderboard** — The title section and overall content were misaligned on the pre-open screen.
- **Removed placeholder text from the teaser view** — Empty podium slots no longer show `Up for grabs` or `No agent yet` text before the leaderboard opens, keeping the pre-open screen clean and focused on prizes.
- **Fixed open-date alignment** — The date shown below the countdown clock is now properly centered.


</Update>
