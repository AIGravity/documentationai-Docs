## Overview

## Release history

1. **Agent Verification Overhaul**
   - **New Features**
     - "Find Another Agent" feedback now lets users select multiple reasons at once instead of just one.
     - Admin review panel rebuilt with a clear split between blocking issues and suggested improvements, per-gate expandable results, and raw JSON hidden by default.
     - Paste-tab publish is now a single click — pasting workflow JSON and pressing "Customize your agent" analyzes and advances in one step.
   - **Updates**
     - Agent verification is significantly faster — the platform now pre-initializes checks in the background while you fill in the form, eliminating the cold-start delay.
     - "Improve with AI" now writes in plain language for non-technical audiences and enforces character limits on all fields. See [Features](/features).
     - Publish Gate verification is stricter — the gate must be a connected step in the workflow, not just listed in metadata.
     - URLs hardcoded inside code steps are now checked against the same domain safety rules as URLs in node parameters.
     - Single-select questions in the agent customization chat now require pressing Confirm before advancing, preventing accidental submissions.
     - Intent and tools steps now combine chip selections with typed text instead of overwriting one with the other.
     - Agent categories cleaned up — "Featured", "Product", and "Agents" tabs removed from the Requested Agents page. See [Features](/features).
   - **Fixes**
     - Content safety failures now always show an actionable message instead of a blank "failed" status.
     - "Improve with AI" no longer generates text that exceeds the form's character limits.
     - Prefilled workflow descriptions are now automatically trimmed to fit before populating the form.
