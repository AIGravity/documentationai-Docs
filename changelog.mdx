## Overview

This changelog tracks verified Gravity platform releases and the related documentation changes. Use it to review shipped features, infrastructure updates, and reader-facing fixes.

## Release history

<Update label="2026-03-07" description="Initial platform release" tags={["feature","improvement"]}>

### New features

- Released the Remix frontend for the primary web application flow. Start with the [Quickstart](/quickstart).
- Released the NestJS API for core platform services and integrations. See the [Architecture Overview](/architecture-overview).
- Released the FastAPI AI service for AI-powered workflows. See the [Architecture Overview](/architecture-overview).

### Infrastructure updates

- Added per-service GitHub Actions pipelines for build, test, and deployment automation. See [CI/CD Pipelines](/ci-cd-pipelines).
- Published Docker images for each service to GitHub Container Registry. See [Docker Images and Packaging](/docker-images-and-packaging).
- Adopted semantic versioning for service releases. See [Service Versioning](/service-versioning).

### Fixes

- None shipped in the initial release.

</Update>
