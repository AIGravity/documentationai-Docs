## Release history

Gravity's latest public release establishes the platform foundation and publishes the first user-facing service documentation. The entry below includes only verified changes that affect readers or operators.

<Update label="Recent release" description="Gravity platform foundation" tags={["feature", "improvement", "bugfix"]}>

### New features

- **Initial Gravity platform foundation** — Gravity now has public web, API, and AI service surfaces documented for readers evaluating the platform shape.
- **Documented service health checks** — Operators can verify the API and AI services with the published [Health Checks](/health-checks) guidance.
- **Independent service packaging** — The web, API, and AI services can be packaged as separate containers, with details in [Docker Images and Packaging](/docker-images-and-packaging).

### Updates

- **Remix-based web shell** — The web surface now uses a Remix application shell for the public homepage and baseline error display. See [Frontend Application Shell](/frontend-application-shell).
- **API reference visibility** — Public API reference pages are available for the [NestJS API](/api-reference/nestjs-api) and [AI Service](/api-reference/ai-service) surfaces.

### Bug fixes

- **Homepage route reliability** — The homepage now resolves consistently for readers reaching the web shell.
- **Error display reliability** — User-visible errors now show clearer fallback messaging instead of confusing failure states.

</Update>
