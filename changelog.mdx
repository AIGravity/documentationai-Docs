## v0.1.0 — March 2026

<Update label="2026-03-07" description="v0.1.0">

### New Features

- **Per-service semantic versioning** — Each service now carries its own version number that automatically increments based on commit messages, producing versioned Git tags, Docker images, and GitHub Releases. [Learn more →](/service-versioning)
- **Automated CI/CD pipelines** — All services build, test, version, and publish Docker images to GitHub Container Registry automatically on every push. GitHub Releases are created on merge to main. [Learn more →](/ci-cd-pipelines)
- **Health check endpoints** — The API and AI service each expose a `/health` endpoint to verify service status at runtime. [Learn more →](/health-checks)
- **One-command local setup** — A bootstrap script initializes the entire project for local development in a single step. [Learn more →](/quickstart)

### Updates

- **Web frontend rebuilt on Remix v2** — The web application now runs on Remix v2, improving routing and build performance.

### Bug Fixes

- **Docker build failure for web service** — Resolved an issue that prevented the web service Docker image from building correctly in CI.

</Update>
