## Release history

<Update label="2025-07-04" description="API updates: credit currencies, builder profile self-heal, and marketplace field descriptions" tags={["feature", "improvement"]}>

<Callout kind="info">

- `POST /api/credits/orders` now accepts `EUR` and `GBP` currencies, in addition to `INR` and `USD`.
- `GET /api/builders/me` now self-creates a builder profile with default values if one does not exist.
- Creator accounts now receive `200` instead of `404` when a default builder profile can be created.
- `POST /api/marketplace/builder-fields` now returns a separate `description` field on each field object, and `question` is derived from the builder label.


</Callout>

## Credit orders: EUR and GBP support

`POST /api/credits/orders` now accepts `EUR` and `GBP` as valid currency values. Order amounts for these currencies are derived from the USD package price using a live FX rate at checkout time. Previously, requests with `EUR` or `GBP` returned a `400 Bad Request` error.

## Builder profile: self-heal on first access

`GET /api/builders/me` now attempts to create a builder profile row with default values when one does not exist for the authenticated user. Creator-typed accounts that have earned credits now receive a `200` response with a default profile instead of a `404`. The endpoint returns `404` only when no user profile record exists at all.

## Marketplace builder fields: question and description separation

`POST /api/marketplace/builder-fields` now includes a separate `description` field on each field object for builder-written helper text. The `question` field is derived from the builder's label and no longer contains the description text. This corrects a previous behavior where `question` could contain the description instead of the label, causing the description to appear as the main prompt.


</Update>
