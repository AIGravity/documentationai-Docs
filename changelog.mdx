## Overview

This changelog tracks notable product changes — new features, updates, and bug fixes — organized newest first.

<Update date="2026-06-30">

### New Features

- **Configurable creator revenue split** — Platform operators can now adjust the revenue split between the platform and builders, and choose whether the builder's share is calculated on the full run price (`gross`) or the profit margin (`margin`). The default basis changed to `gross`, so builders earn a percentage of the total charge per run. See [Configuration Reference](/configuration-reference).

### Updates

- **Smarter AI chat assistant** — The AI assistant no longer repeats questions you've already answered, detects when a named app isn't supported, and hands off to automation faster once you provide a task and a single app.

### Bug Fixes

- **Builder earnings dashboard** — Earnings now reflect real ledger data instead of placeholder demo values. The available-to-withdraw balance is calculated from actual lifetime earnings minus withdrawn amounts. See [Features](/features).
- **AI chat server error** — Fixed a server error (HTTP 500) that occurred on successful chat turns. See [AI Service](/api-reference/ai-service).



</Update>
